# รายงาน QA — งานครบ (1 ต.ค. 2569)

ผู้ทดสอบ: Claude (บทบาท Software Tester) · สาขา `claude/import-list-from-excel-38cp38` · **ยังไม่ได้ deploy** (รอผู้ใช้สั่ง)

## สรุปสั้น
- ตรวจ **ทุกหน้า** (หน้าหลัก สแกน เช็คชื่อ สมุดคะแนน สุ่มชื่อ รายงาน นักเรียน ตั้งค่า 7 หมวด) × 3 ขนาดจอ (คอม/แท็บเล็ต/มือถือ) × 2 ธีม (สว่าง/มืด) และลองใช้งานจริง 48 ขั้นตอนในเบราว์เซอร์
- **ความหน่วงมีสาเหตุชัด 2 อย่าง:** (1) ฐานข้อมูลอยู่อเมริกา แต่ครูอยู่ไทย ทุกรอบที่คุยกับฐานข้อมูลใช้เวลา ~200 ms (2) โค้ดเดิมคุยกับฐานข้อมูลต่อกันทีละรอบ (หน้าเดียว 8–18 รอบ) และหน้าจอรอให้ครบก่อนถึงขยับ
- **แก้ฝั่งโค้ดแล้ว:** กดตาซ่อนคะแนนจาก **4.3 วินาที → 0.07 วินาที** (หน้าจอเปลี่ยนทันที), เปิดสมุดคะแนน 1.9 → 0.85 วินาที, เปิดรายงาน 2.2 → 0.83 วินาที, เลือกธีม 1.6 → 0.5 วินาทีฝั่งเซิร์ฟเวอร์
- **ที่เหลือคือระยะทาง:** ย้ายฐานข้อมูลมาเอเชียจะเหลือรอบละ ~20 ms (ขั้นตอนอยู่ใน `MOVE-DB-TO-ASIA.md` — ยังไม่ได้ทำ รอสั่ง)
- พบ **bug 3 ข้อที่ร้ายแรง (P1)** และ 8 ข้อ P2 แก้ครบแล้วพร้อม test ทั้งหมดผ่าน (476 unit/API · 48/48 ขั้นตอนในเบราว์เซอร์ · e2e ออฟไลน์/ต้อนรับ/ซ้อมใช้งานจริง ผ่านหมด)

## ความเร็ว (จำลองฐานข้อมูลไกล 200 ms/รอบ — เหมือนของจริงตอนนี้)
“หน้าจอตอบ” = เวลาตั้งแต่คลิกจนเห็นผล · “เซิร์ฟเวอร์” = เวลารวมของคำขอที่เกี่ยวข้อง

| การกระทำ | หน้าจอตอบ ก่อน → หลัง | เซิร์ฟเวอร์ ก่อน → หลัง |
|---|---|---|
| คลิกตา ซ่อน/แสดงคะแนน | **4,298 → 68 ms** | 4,247 → 818 ms (รันเบื้องหลัง) |
| เปิดสมุดคะแนน | 1,926 → 849 ms | 1,870 → 797 ms |
| เปิดรายงาน | 2,159 → 831 ms | 2,108 → 778 ms |
| เปิดนักเรียน / หน้าหลัก | 35 / 16 ms (เห็นโครงก่อน) | 2,110 → 801 / 1,445 → 777 ms |
| “ทั้งห้องส่งแล้ว” | 5,349 → 2,095 ms (มีวงกลมหมุนบนปุ่มแล้ว) | 5,244 → 2,029 ms |
| เลือกธีม | 62 → 68 ms | 1,642 → 493 ms |
| เปิดลิ้นชักนักเรียน (โหลดข้อมูลในลิ้นชัก) | 86 → 31 ms | 2,818 → 1,300 ms |
| รายงาน: สลับรายเดือน | 33 → 35 ms | 1,850 → 777 ms |

ทำอะไรไป
1. **คำขอทุกครั้งเคยถามฐานข้อมูลเรื่องเดิมซ้ำ 3–5 รอบก่อนเริ่มงานจริง** (เวอร์ชันระบบ / ล็อกกู้คืน / epoch / เซสชัน — บางเส้นถามเซสชันซ้ำสองรอบ) → รวมเป็น **รอบเดียว** (`worker/app.ts`, `worker/lib/auth.ts`)
2. สมุดคะแนน / รายงาน / หน้าหลัก / บันทึกงาน / ตั้งค่า / เช็คชื่อ / ทั้งห้อง: **คำถามที่ไม่พึ่งกันถูกถามพร้อมกัน** และเขียนบันทึกประวัติ (audit) ในชุดเดียวกับข้อมูล
3. ฝั่งหน้าจอ: ตาซ่อนคะแนน/เปิดปิดรับงาน **ขยับทันทีแล้วค่อยบอกเซิร์ฟเวอร์** (ถ้าพลาดย้อนกลับ+แจ้ง), กดซ้ำระหว่างรอถูกเมิน, ปุ่ม “ทั้งห้อง” มีวงกลมหมุนและกดซ้ำไม่ได้
4. เพิ่มหัว `Server-Timing` ในทุกคำตอบ: เปิด DevTools → Network → คลิกคำขอ → Timing จะเห็นเวลาฝั่งเซิร์ฟเวอร์จริง แยกออกจากเวลาเครือข่าย

## เรื่องที่ยังไม่แก้ (ตั้งใจ / รอตัดสินใจ)
1. **ความหน่วงที่เหลือ = ระยะทางไปฐานข้อมูล** → ย้าย D1 มา APAC (`MOVE-DB-TO-ASIA.md`) — **รอคุณสั่ง**
2. สมุดคะแนน: เมื่อซ่อนคะแนนงานใดงานหนึ่ง “สะสม” ของทุกคนเป็น `•••` ทั้งคอลัมน์ตามที่ขอ — ข้อมูลตัวอย่างซ่อนข้อสอบไว้ จึงเห็น `•••` ตลอด ถ้าอยากให้สะสมนับเฉพาะงานที่ไม่ซ่อนแทน บอกได้
3. หน้ารายงานตอนโหลดไม่สำเร็จยังโชว์ปุ่ม “พิมพ์/ส่งออก Excel” (กดแล้วไม่มีข้อมูลให้พิมพ์)
4. ป้าย “ออนไลน์” สีเขียวตอนที่ wifi ติดแต่เซิร์ฟเวอร์ตอบไม่ได้ — ป้ายดูจากสถานะเบราว์เซอร์ ไม่ใช่จากการคุยกับเซิร์ฟเวอร์จริง
5. “ทั้งห้องส่งแล้ว” ยังใช้ ~2 วินาทีที่ระยะทางปัจจุบัน (จะเหลือ ~0.3 วินาทีหลังย้าย DB)
