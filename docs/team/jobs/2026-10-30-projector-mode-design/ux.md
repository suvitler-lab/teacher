# UX: โหมดฉายจอ (iPad สะท้อนจอขึ้นโปรเจกเตอร์)

โดย UX/UI Designer · 2026-10-30 · อ้างอิง `brief.md`, D20–D22, D26 · ♿ 👤 · ไม่แก้โค้ดแอป

## ผู้ใช้และงานหลัก

ครูคนเดียวถือ iPad แนวนอน (1024×768 / 1180×820 / 1366×1024) สะท้อนจอผ่าน AirPlay/Apple TV ขึ้น **สมาร์ททีวี 55–65" (D27)** เด็กนั่งไกลถึง ~8–10 ม. ห้องมักสว่าง · ครูต้องกดเปิดเองด้วยนิ้วเดียวก่อนฉาย และมั่นใจว่าคะแนน/ชื่อที่ทำให้เด็กอายจะไม่ขึ้นจอ

## 1) เปิด/ปิด

- **ปุ่มเปิด**: `presentation` + ข้อความ "โหมดฉายจอ" ในแถบหัวหน้า (actions ขวาบน) ของ 4 หน้าเท่านั้น · สูง 44px (ผ่าน D22) · ไม่ใส่ในเมนูซ้าย (ไม่อยากให้กดโดยบังเอิญ/ไม่ใช่ทุกหน้า)
- Random เดิมมี "จอใหญ่" (`device-tv`, Space) → รวมเป็นปุ่มเดียวนี้ (ใช้ `presentation` ทั้ง 4 หน้า; `device-tv` เลิกใช้เพื่อ 1 ไอคอน = 1 ความหมาย) · Space ยังใช้สุ่มในหน้า Random
- **เปิดแล้ว**: ซ่อนเมนูซ้าย/แถบล่าง/แถบหัวเดิม → เหลือแถบฉายสูง ~84px: ชื่อหน้า (40px) · ป้าย **"กำลังฉายจอ"** (จุด + ขอบ 3px, 26px — มีตัวหนังสือ ไม่พึ่งสี) · ปุ่มออก `x` 64px
- **ปิด (กันพลาด)**: ออกแล้วคะแนนจะโผล่ขึ้นจอ จึงต้อง **กดค้าง 1 วินาที** ที่ปุ่ม `x` (วงแหวนเติมขณะกด) หรือกด `Esc` บนคีย์บอร์ด · แตะเฉย ๆ แล้วขึ้นข้อความเล็ก "กดค้างเพื่อออกจากโหมดฉาย" ใต้ปุ่ม (หายใน 3 วิ) · การ "เปิด" แตะครั้งเดียว (ทิศปลอดภัย)
- **จำค่า**: โหมดจำใน `sessionStorage` ต่อแท็บ (รีเฟรชระหว่างคาบยังฉายอยู่; ปิดแอป/วันใหม่ = ปกติ) · **ธีมฉาย (เข้ม/สว่าง)** จำถาวรต่อเครื่อง (`localStorage`) · สลับธีมทำก่อนเปิดฉาย (ตัวเลือกข้างปุ่มเปิด) ไม่มีปุ่มธีมบนจอฉาย
- **สลับหน้าระหว่างฉาย**: โหมดคงอยู่ข้ามหน้า (sessionStorage) · ลิงก์เล็ก "ไปหน้าอื่น" มุมล่างขวา เปิดปุ่ม 4 หน้าขนาด 64px (ไม่มีเมนูอื่น) — ตัดสินรายละเอียดตอนสร้าง

## 2) ซ่อน/แสดง ต่อหน้า

| หน้า | แสดง (ขยาย) | ซ่อนตอนฉาย |
|---|---|---|
| สุ่มชื่อ/จับกลุ่ม | ชื่อที่สุ่มได้ 84px + เลขที่ · ปุ่ม "สุ่มคนต่อไป" 80px · การ์ดกลุ่ม (ชื่อเล่น 28px) | ตัวเลือกไม่สุ่มซ้ำ/จำนวนกลุ่ม (ตั้งก่อนเปิดโหมด) · รายการยกเว้น · คะแนน/ประวัติรายคน |
| สแกนส่งงาน | ชื่อคนที่เพิ่งสแกน + ✓ "ส่งแล้ว" 64px · "ส่งแล้ว 21 จาก 32 คน" + แถบ · ผังเลขที่: ✓ = ส่งแล้ว, กรอบประ = ยังไม่ส่ง **แสดงเลขที่อย่างเดียว ไม่มีชื่อ** | **คะแนน** (10/10, รอคะแนน) · ปุ่ม "จบรอบสแกน"/ยกเลิกการส่ง/แตะรับแทน · "รอส่งขึ้นระบบ" · ปุ่มเลือกงาน/ห้อง/วิธีให้คะแนน · ปุ่มคัดลอกรายชื่อค้าง |
| เช็คชื่อ | "มาแล้ว 28 จาก 32 คน" · ผังเลขที่+ชื่อเล่นเฉพาะคนที่มาแล้ว ✓ · ป้ายคนล่าสุด "น้องภู มาแล้ว" | % มาเรียน · เวลาเข้า · **สถานะ ขาด/ป่วย/ลา/สาย (ไม่แสดงเป็นคำเลย — คนที่ยังไม่มา = กรอบประ เลขที่เท่านั้น)** · ปุ่มมาทั้งหมด/บันทึก/แก้สถานะ · ปฏิทิน |
| รายงาน | ภาพรวมห้อง: ส่งแล้ว X/Y ชิ้น · ค้างรวม N ชิ้น (จำนวนเท่านั้น) · รายงานแต่ละชิ้น (แถบ + "21/32 ส่งแล้ว") | คะแนนเฉลี่ย · % รายคน · ตาราง "ต้องติดตาม" · ชื่อเด็กที่ค้าง · ปุ่มส่งออก/พิมพ์ · ตัวกรองปีการศึกษา |

หลักการ: ข้อมูลระดับ **ห้อง** แสดงได้ · ข้อมูลระดับ **รายคน** ที่เป็นลบ/คะแนน ซ่อน · ชื่อโผล่เฉพาะแง่บวก (คนที่เพิ่งส่ง/มาแล้ว)

## 3) ขนาดตัวอักษรที่ 1024×768 (D27: ปลายทางคือสมาร์ททีวี 55–65")

ฐานคิดใหม่: ทีวี 55" สูง ~0.68 ม. / 65" สูง ~0.81 ม. · iPad 4:3 เต็มสูง ใช้ ~75% ของความกว้างจอ → 768px = ความสูงทีวี → **1px ≈ 0.9 มม. (55") ถึง 1.05 มม. (65")** · ที่ 10 ม. ตัวอักษรไทยอ่านออกได้เมื่อขนาดตัว ≥ 1/300 ของระยะ (≈ 33 มม. → 37px ที่ 55") และสบายที่ 1/200 (50 มม. → 48–56px) · ค่าเดิม 26px (คิดแบบโปรเจกเตอร์ภาพใหญ่กว่า) **เล็กเกินสำหรับทีวี** จึงปรับขึ้น

ตัวปรับ **"ขนาดตัวอักษร"** 3 ระดับ (ตั้งก่อนเปิดฉาย อยู่ข้างปุ่มเปิดเหมือนธีม; จำต่อเครื่อง `localStorage`; ค่าเริ่มต้น = "ใหญ่"):

| ระดับ | ข้อความรอง (ต่ำสุด) | ตัวเลขสรุป | ชื่อหลัก | ปุ่ม | ผังเลขที่ 32 ช่อง (สแกน/เช็คชื่อ) |
|---|---|---|---|---|---|
| มาตรฐาน | 32px | 56px | 72px | สูง 64px | 8 คอลัมน์×4 แถว · เช็คชื่อแสดง เลขที่+ชื่อเล่นย่อ (ellipsis) 6×6 |
| **ใหญ่ (เริ่มต้น)** | 40px | 72px | 96px | สูง 72px | 8×4 **เลขที่อย่างเดียว** (ชื่อคนล่าสุดอยู่ในป้ายด้านบน) |
| ใหญ่มาก | 48px | 88px | 120px | สูง 80px | 8×4 เลขที่ + ✓ เดียว · เนื้อหารองที่ไม่สำคัญ (หัวงาน/ห้อง) ย่อลงเหลือบรรทัดเดียว · ชื่อยาวขึ้น 2 บรรทัดได้ |

- ทุกระดับ 32 ช่องต้องไม่ล้นความสูง 768px (ไม่มี scroll ในโหมดฉาย) — ถ้าเกิน ลดข้อมูลรอง ไม่ลดตัวอักษรหลัก · ผังช่องสูง ≥ 64px · ไอคอน ≥ 40px · ขอบ 3px
- ใช้หน่วยสัมพัทธ์กับความสูงจอ (`--u: 100vh/768`) ให้ 1180×820 / 1366×1024 โตตามจอ · mockup เดิม (ค่า 26px) เป็นระดับต่ำกว่า "มาตรฐาน" — ใช้แค่ทิศทาง layout ไม่ใช่ขนาดสุดท้าย

## 4) สี/คอนทราสต์ (อ้าง VP-1 ผ่าน AA; โหมดฉายใช้ AAA ≥ 7:1 สำหรับข้อความ)

โปรเจกเตอร์ในห้องสว่างจะ "ดำจางเป็นเทา" และสีอิ่มซีด → ต้องเผื่อคอนทราสต์ ไม่ใช้ `--text-muted`/สีจาง/เส้น 0.5px · ขอบ ≥ 3px

| token โหมดฉาย | เข้ม (**แนะนำ**) | สว่าง |
|---|---|---|
| พื้น / การ์ด | `#0b1220` / `#151e33` | `#ffffff` / `#eef2f8` |
| ข้อความหลัก / รอง | `#ffffff` 18.7 / `#cdd5e3` 12.7 | `#0b1220` 18.7 / `#2c3648` 12.2 |
| ส่งแล้ว (ตัวหนังสือ/ขอบ) | `#6ee7a8` 10.8 | `#0d6a3a` 6.0* |
| ค้าง/เตือน | `#ff9a9a` 8.2 / `#ffd166` 11.5 | `#9b1c1c` 7.3 / `#7a4b00` 6.6 |
| เน้น (ปุ่ม/ป้าย) | `#9cc2f2` 9.0 (ตัวหนังสือบนปุ่ม `#0b1220`) | `#164a9e` 7.5 |
| เส้นขอบ | `#5b6a8a` หนา 3px | `#55627a` หนา 3px |

(ค่า = อัตราส่วนคอนทราสต์คำนวณแล้ว; *ผ่าน AA ที่ตัวใหญ่ ใช้เฉพาะตัวหนา ≥ 26px)
- **เข้มเป็นค่าเริ่มต้น**: ห้องเรียนปิดไฟหน้าจอ/ผ้าม่านบางส่วนทั้งนี้พื้นขาวทั้งผืนแสบตาเด็กแถวหน้า และโปรเจกเตอร์ส่วนมากเก็บตัวขาวได้ดีกว่าเก็บดำ → ใช้น้ำเงินเข้มไม่ใช่ดำสนิท · **สว่างไว้เป็นทางเลือก** ถ้าห้องสว่างมาก (ผ้าม่านเปิด) · ครูลองหน้างานจริงแล้วเลือก (ดูคำถามข้อ 2)
- ไม่พึ่งสีอย่างเดียว: ส่งแล้ว = ✓ + ตัวหนา + ขอบทึบ vs ยังไม่ส่ง = กรอบประ ไม่มี ✓ · ค้าง = ข้อความ "ยังไม่ส่ง" ไม่ใช่แค่สีแดง

## 5) กันกดพลาดระหว่างฉาย

- เมนู/แถบล่าง/ตั้งค่า/ออกจากระบบ/ปุ่มลบ/ยกเลิก/จบรอบ/ส่งออก ไม่แสดง (ตาราง 2) · ปุ่มที่เหลือ: สุ่ม, ไปหน้าอื่น, ออก (กดค้าง)
- สแกนวิธี "กรอกทีละคน" (พิมพ์คะแนน) **ไม่รองรับในโหมดฉาย**: ช่องพิมพ์จะโชว์คะแนนที่ครูกด → เปลี่ยนอัตโนมัติเป็น "รับงานก่อน" พร้อมแจ้งครู (toast ก่อนเปิด) · ข้อความแจ้งเตือน/error ที่มีชื่อ+คะแนนไม่แสดงบนจอ แสดงเป็น "ไม่รู้จักรหัสนี้" แบบไม่ระบุข้อมูลส่วนบุคคล
- เปิด/ปิดไม่ลบข้อมูล; ไม่มีการกระทำที่ย้อนกลับไม่ได้ในโหมดฉาย (จึงไม่ต้องมีกล่องยืนยันลบ)

## 6) 4:3 บน 16:9 (ทีวี)

- AirPlay mirror ใส่ขอบดำซ้าย-ขวาเอง (iPad 4:3 ใช้ 75% ของความกว้าง) · ตรวจจอนอกไม่ได้ (D26) → ออกแบบสำหรับ 4:3 เต็มความสูง **ไม่มีคอลัมน์ข้าง ขอบใน 24px** ใช้ทุกพิกเซลของ 768px · ไม่มีเนื้อหา/ปุ่มที่ติดขอบเพราะอาจถูกโปรเจกเตอร์ครอบ (overscan) → เว้น 24px (overscan ของทีวี — ไม่ชิดขอบ)
- ใช้ PWA เต็มจอ (ติดตั้งหน้าจอ Home) เพื่อไม่มีแถบ Safari กินพื้นที่ — ใส่เป็นข้อแนะนำในหน้าตั้งค่า (ไม่ใช่ใน job แรก)
- 1180×820 / 1366×1024 ใช้สัดส่วนเดียวกัน (4:3 ≈) ย่อ-ขยายด้วยหน่วย `--u`

## การเข้าถึง

- Focus: ปุ่มเปิดอยู่ในลำดับ actions · ในโหมดฉาย focus ไปที่ปุ่มหลักของหน้า แล้วปุ่มออก; `Esc` = ออก (บนคีย์บอร์ดภายนอก) · `aria-pressed` ที่ปุ่มเปิด · ป้าย "กำลังฉายจอ" เป็น `role="status"` ครั้งเดียวตอนเปิด
- ไม่พึ่งสีอย่างเดียว (ข้อ 4) · ไม่มีแอนิเมชันกะพริบ (`prefers-reduced-motion`) · พื้นที่กด 64px (> 44px ของ D22) · ทุกช่องมี label (ช่องสแกนซ่อนไว้ มี aria-label)

## คำถามให้เจ้าของงาน

ตอบแล้ว (D27): งานค้าง = จำนวนอย่างเดียว · ปิดด้วยกดค้าง 1 วิ · ธีมเริ่มต้นเข้ม (สว่างเป็นทางเลือก) · ไม่มีคำถามค้าง
