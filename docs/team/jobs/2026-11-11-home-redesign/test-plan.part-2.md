## หน้าเช็คชื่อ (AC-81–106)

ผลคำนวณมือ (BR-19, 21, 22): FA1 เช็คแล้ว 29+2+1+0+2 = **34** · ยังไม่เช็ค 45−34 = **11** · มาเรียน 29+2 = **31** · % = 3100 ÷ 34 = 91.18 → **91** · ทีวี 3100 ÷ 45 = 68.89 → **69%** · FA3 % = 4300 ÷ 45 = 95.56 → **96** · รอเลือก 2 → ยังไม่เช็ค 45−34−2 = **9** · FM1: วัน 3100÷33 = 93.9 → 94 · 3000÷32 = 93.75 → 94 · 2600÷31 = 83.9 → 84 · เดือน (31+30+26)×100 ÷ (33+32+31) = 8700÷96 = 90.6 → **91%** · FM2: รวมก่อนหาร 1100÷21 = 52.38 → **52%** (ถ้าเฉลี่ย % = 75 → FAIL) · FA1 + เดือนที่รวมวันนี้: (87+31)×100 ÷ (96+34) = 11800÷130 = 90.77 → 91% "เช็คแล้ว 4 วัน"
