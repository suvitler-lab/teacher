## ผลตรวจที่ UX ฝากไว้

1. **Projector.tsx กับหน้านักเรียน (ยืนยันจากโค้ดแล้ว):** `ProjectorShell` รับ `page` แค่ scan · attendance · random · reports และเมนู "ไปหน้าอื่น" มี 4 หน้านี้ · `Students.tsx` ไม่อ่าน `projectorOn` และไม่มีปุ่มฉายจอ · `projectorOn` อยู่ใน sessionStorage ทั้งแท็บ → ถ้าเข้า `#/students` ระหว่างฉายจอ (ย้อนกลับ/ลิงก์/รีโหลด) **หน้านักเรียนเต็มรูป (ชื่อ รหัส % รายคน ปุ่มแก้) ขึ้นทีวี** = ช่องรั่ว → AC-197 เพิ่ม "students" ใน `ProjectorShell` (หน้าบ้านล้วน) · ST-S23 "overlay กลาง" = ใช่
2. **`followUp` มี id งานไหม (ยืนยันแล้ว):** ไม่มี — `followUp.missing` เป็น `string[]` ชื่องาน (report.ts:42, :108) และลิ้นชักหาเพื่อนด้วย `title` (StudentDrawer.tsx:76) · แต่ payload เดิมมี `assignments[].id` + submissions และ `workState` เดียวกัน → หา id งานค้างได้ในเครื่อง (เพิ่มฟิลด์ id ใน report.ts โดย `missing` ชื่อเดิมไม่เปลี่ยน เพราะ `followUpText` ใช้) · `/gradebook?class&asg=` มีอยู่แล้ว → AC-184 ทำได้ด้วยข้อมูลเดิม **ไม่ต้องเพิ่ม API**
