# ข้อเสนอเมนู — เพิ่ม ลด หรือคงเดิม (T-05)

สถานะ: รอเจ้าของงานเลือก (Gate เมนู) · ผู้เขียน: SA · 2026-11-11
อ้างอิงโค้ดจริง: `src/components/Shell.tsx` (เมนู), `src/app.tsx` (หน้า 8 หน้า), `src/pages/Home.tsx` (ปุ่มลัด 4), `Settings.tsx` / `Students.tsx` / `Gradebook.tsx` / `Reports.tsx`

## สรุปสั้น (อ่านแค่ส่วนนี้ก็พอ)

- เมนูตอนนี้มี **8 หน้า 4 กลุ่ม** (D35) งานทุกคาบ (สแกน เช็คชื่อ สุ่มชื่อ สร้างงาน) **กดครั้งเดียวถึง** จากหน้าหลักอยู่แล้ว
- ของที่ "ซ่อนลึก" จริงมี 4 อย่าง: คัดลอกงาน (4 ครั้ง) · สำรองข้อมูล · ห้อง/วิชา/ภาคเรียน (อยู่ในตั้งค่า ชื่อหมวดว่า "ข้อมูลพื้นฐาน") · พิมพ์สติกเกอร์ QR (อยู่ในหน้านักเรียน)
- ทีมเสนอ 3 ทาง: **ก) คงเดิม 8** · **ข) ลดเหลือ 7** (รวมคะแนนกับรายงาน) · **ค) เพิ่มเป็น 11** (ลิงก์ลัด 2 + ตารางสอน 1 ในอนาคต)
- **ค่าแนะนำ: ก) คงเดิมตอนนี้** แล้วเพิ่ม "ตารางสอน" เข้ากลุ่ม "วันนี้" เมื่องานแยก C (ตารางสอน) สร้างเสร็จ — ส่วนของที่ซ่อนลึกแก้ด้วยปุ่มในหน้า ไม่ต้องเพิ่มเมนู

## 1. งานที่ครูทำจริง → ตอนนี้กดกี่ครั้ง

นับจากหน้าหลัก · "iPad" = มีแถบเมนูซ้าย (rail) · "มือถือ" = แถบล่าง 5 ช่อง + แผ่น "เพิ่มเติม" · นับเฉพาะการกดจนถึงจุดเริ่มทำงาน (ไม่นับการพิมพ์/สแกน)

| ความถี่ | งาน | iPad | มือถือ | ผ่านทางไหน |
|---|---|---|---|---|
| ทุกคาบ | สแกนรับงาน | 1 (+เลือกงาน/ห้อง 1–2) | 1 | ปุ่มลัด "สแกนส่งงาน" หรือเมนู สแกน · มีชิป "สแกนต่อจากรอบล่าสุด" |
| ทุกคาบ | เช็คชื่อ | 1 | 1 | ปุ่มลัด / เมนู เช็คชื่อ / แถบล่าง |

| ทุกวัน | ดูเด็กที่ต้องติดตาม | 0 (การ์ดบนหน้าหลัก) | 0 | หน้าหลัก → "ทั้งหมด" ไปรายงาน |
| ทุกสัปดาห์ | คัดลอกงานให้ห้องอื่น / ปีถัดไป | **4** | **4** | คะแนน → เลือกงาน → เมนู ⋯ → คัดลอกงาน |

| ทุกสัปดาห์ | ส่งสรุปเข้า LINE ผู้ปกครอง | 2 | 3 | รายงาน → คัดลอกไป LINE (มือถือต้องผ่าน "เพิ่มเติม") |
| ทุกสัปดาห์ | สำรองข้อมูล | **2** | **3** | ตั้งค่า → สำรองข้อมูล · ไม่มีเตือนบนหน้าหลัก |
| ทุกสัปดาห์ | ดูนักเรียนรายคน | 2 | 3 | นักเรียน → แตะชื่อ |
| ต้นภาค | สร้างห้อง / วิชา / ภาคเรียน | **2** | **3** | ตั้งค่า → "ข้อมูลพื้นฐาน" (ชื่อหมวดไม่บอกว่ามีห้อง/วิชา) |
| ต้นภาค | นำเข้านักเรียนจาก Excel | 2 | 3 | นักเรียน → นำเข้า Excel |
| ต้นภาค | พิมพ์สติกเกอร์ QR | **2** | **3** | นักเรียน → พิมพ์สติกเกอร์ QR (ครูอาจหาในตั้งค่า "การสแกน" ก่อน) |
| ปลายภาค | ส่งออก Excel / พิมพ์รายงาน | 2 | 3 | รายงาน → ส่งออก Excel / พิมพ์ |
| นาน ๆ ครั้ง | ดูประวัติการแก้ไข · อุปกรณ์/รหัสผ่าน · หน้าตา/ธีม (ใหม่) | 2 | 3 | ตั้งค่า → หมวดนั้น |

**จุดที่ซ่อนลึก/หายาก (เรียงจากกระทบครูมากไปน้อย)**
1. **คัดลอกงาน** 4 ครั้ง ซ่อนในเมนู ⋯ ของงานที่เลือก — ครูสอนหลายห้องใช้บ่อย
2. **สำรองข้อมูล** อยู่ลึกในตั้งค่า และไม่มีอะไรเตือนบนหน้าหลัก — ลืมง่าย เสี่ยงข้อมูลหาย
3. **ห้อง/วิชา/ภาคเรียน** อยู่ใต้ชื่อ "ข้อมูลพื้นฐาน" ในตั้งค่า — ทำปีละ 2 ครั้ง จำไม่ได้ว่าอยู่ไหน
4. **สติกเกอร์ QR** อยู่หน้านักเรียน แต่ครูคิดว่าเป็นเรื่อง "สแกน" — ทำต้นภาค/เมื่อบัตรหาย
5. มือถือ: **รายงาน** และ **สุ่มชื่อ** ต้องผ่าน "เพิ่มเติม" (2 ครั้ง) — ครูใช้ iPad เป็นหลัก จึงกระทบน้อย

ข้อสังเกต: งานทุกคาบ/ทุกวันถึงได้ใน 1 ครั้งแล้ว **ปัญหาไม่ได้อยู่ที่จำนวนเมนู** แต่อยู่ที่ของนาน ๆ ใช้ที่ซ่อนอยู่ในหน้าอื่น

## 3. ค่าแนะนำ: ก) คงเดิม + เพิ่ม "ตารางสอน" เมื่องาน C เสร็จ (ผสม ก+ค บางส่วน)

เมนูวันนี้ = ก) 8 รายการเดิมทุกอย่าง · เมื่องานแยก C ปล่อย → เพิ่ม `timetable` "ตารางสอน" ต่อจากหน้าหลักในกลุ่ม "วันนี้" (เป็น 9) · ของซ่อนลึกแก้ **ในหน้า** ไม่ใช่ในเมนู (เสนอเป็นงานเล็กแยก ไม่อยู่ในรอบนี้):
- สำรองข้อมูล → แถว "ยังไม่ได้สำรองข้อมูล N วัน" ใน "ต้องทำตอนนี้" บนหน้าหลัก (ใช้ `last_backup_at` ที่มีอยู่)
- บัตร QR → ปุ่ม "พิมพ์บัตร QR" ในตั้งค่า หมวด "การสแกน" ชี้ไปหน้านักเรียน
- คัดลอกงาน → ปุ่มคัดลอกเห็นตรง ๆ ในแถบงานที่เลือก (ไม่ต้องเปิด ⋯)

เหตุผลจากมุมครู
1. งานทุกคาบ (สแกน เช็คชื่อ สุ่มชื่อ สร้างงาน) กดครั้งเดียวถึงอยู่แล้ว — เพิ่มหรือลดเมนูไม่ทำให้คาบสอนเร็วขึ้น
2. ครูเพิ่งคุ้นเมนูชุดนี้ได้ 1 สัปดาห์ และกำลังจะได้หน้าหลัก + ธีมใหม่ — เปลี่ยนทีละอย่างจะไม่หลง
3. ของที่หาไม่เจอเป็นของ "นาน ๆ ใช้" — เตือนตอนถึงเวลา (เช่นสำรองข้อมูล) ได้ผลกว่าวางไว้บนเมนูตลอด
4. iPad แนวนอนเวลาฉายจอ เมนูสั้น = ปุ่มใหญ่ กดแม่นแม้ยืนสอน
5. ตารางสอนเป็นงานที่ดูทุกเช้า สมควรมีที่บนเมนู — แต่เพิ่มเมื่อหน้านั้นมีจริงเท่านั้น ไม่ทำปุ่มว่าง

## 4. คำถามถึงเจ้าของงาน

| # | คำถาม | ตัวเลือก | ค่าแนะนำ + เหตุผล |
|---|---|---|---|
| Q1 | เมนูหลักเอาแบบไหน | ก) คงเดิม 8 · ข) ลด 7 (รวมคะแนน+รายงาน) · ค) เพิ่ม 11 (บัตร QR, สำรองข้อมูล, ตารางสอน) · ง) ก ตอนนี้ + ตารางสอนเมื่อพร้อม | **ง)** งานทุกคาบถึงใน 1 ครั้งแล้ว ไม่ต้องเปลี่ยนสิ่งที่เพิ่งคุ้น และมีที่ให้ตารางสอนในอนาคต |
| Q2 | ของซ่อนลึก (สำรองข้อมูล · บัตร QR · คัดลอกงาน) แก้อย่างไร | ก) ไม่แก้ตอนนี้ · ข) แก้ในหน้า (เตือนสำรองบนหน้าหลัก, ปุ่มบัตร QR ในตั้งค่า, ปุ่มคัดลอกเห็นตรง ๆ) เป็นงานเล็กแยก · ค) ใส่เป็นเมนูลัด (ทาง ค) | **ข)** เตือนตอนถึงเวลาจริง เมนูไม่ยาว · ไม่แตะหลังบ้าน |
| Q3 | ชื่อหมวด "ข้อมูลพื้นฐาน" ในตั้งค่า | ก) คงเดิม · ข) เปลี่ยนเป็น "ห้องเรียน วิชา ภาคเรียน" | **ข)** หัวข้อในหมวดชื่อนี้อยู่แล้ว ครูหาเจอตอนต้นภาคโดยไม่ต้องเดา · เปลี่ยนแค่ป้าย ไม่เปลี่ยน route |
