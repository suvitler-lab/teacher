# dev-notes T-42 — หน้าสุ่มชื่ออ่าน `?class=`

## ทำอะไร
- `src/pages/Random.tsx`: อ่าน `routeParams().class` — ถ้าเป็นห้องใน `activeClasses` (ไม่เก็บถาวร/ปีนี้) ใช้เป็นห้องเริ่มต้น และสลับห้องเมื่อมีลิงก์ใหม่ขณะเปิดหน้าอยู่ · ไม่รู้จัก/เก็บถาวร/ต่างปี → ห้องแรกเหมือนเดิม
- "จำไว้" = ใช้ state `classId` เดิมของหน้า (หน้านี้ไม่มีที่เก็บห้องล่าสุดข้ามการเปิด — Q2 ใน requirements ระบุ "ห้องแรกตามเดิม") ไม่เพิ่มกลไกใหม่
- ไม่เปลี่ยนพฤติกรรมอื่น ไม่แก้ URL เมื่อกดชิปห้อง

## เทสต์
- `test/unit/hr-rndclass-link.test.tsx` 4 ข้อ: ห้องที่ลิงก์ · ห้องไม่รู้จัก/เก็บถาวร · ไม่มีพารามิเตอร์ · ลิงก์มาขณะเปิดหน้า
- ถอดการแก้ (linkedOk = false) แล้วลองจริง: ล้ม 2 ข้อ (ข้อ 1 และ 4) ตามคาด → คืนโค้ดแล้ว
