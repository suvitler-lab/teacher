### ตอบ "จุดคลุมเครือของ interface" (7 ข้อ)
1. ไม่มาวันนี้ → `model.rooms[i].absent[]` (ต่อห้อง) หรือ `model.d.absentToday` (ปลอดภัยแล้ว) · นับต่อสถานะให้ filter เอง (ลำดับแสดง ขาด ลา ป่วย สาย)
2. ต้องติดตามต่อห้อง (ข) → `model.rooms[i].follow` (ไม่ต้องเรียก followGroups เอง)
3. คัดลอก LINE → `row.secondary[]` ต่อห้อง + `copyDueToLine(row.due, s.classId)`; เมื่อซ่อนชื่อ model ตัด `secondary` ให้แล้ว (ยังต้องไม่แสดงรายชื่อ)
4. "N คน": ใช้ `att.total` คู่กับเช็คชื่อ · `studentCount` = รายชื่อในเครื่อง (0 จนกว่าโหลด) ใช้เมื่อไม่มี att
5. `rate`/`att.pct` null = "—" ไม่ใช่ 0% · `att` null = ไม่มีแถวเช็คชื่อ ("—") ≠ `att.progress==="none"` ("ยังไม่เช็ค")
6. คีย์ `open` คนละใบใน ก/ค — ชื่อจาก `LAYOUT_CARD_META[layout]` เท่านั้น (ห้ามใช้ `CARD_META` เดิม ซึ่งเป็นของ Legacy)
7. ป้าย level: ใช้ `row.levelLabel` เป็นคำเสมอ · สี: must=`--text-danger/--bg-danger`, should=`--text-warning/--bg-warning`, later=`--text-secondary/--surface-1`, พรุ่งนี้ = later (แนะนำ ทั้ง 3 โครงใช้ชุดนี้)
