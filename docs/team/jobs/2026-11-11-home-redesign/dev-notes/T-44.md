## ธง 🔄 การสุ่ม / ความสมบูรณ์ข้อมูล
- ตรรกะสุ่มไม่ถูกแตะ; หน้าแค่ส่งค่าให้ `pickNext` เหมือนเดิม
- ประวัติยังไม่โหลด (IndexedDB) = นับเป็น "กำลังโหลด" ปุ่มสุ่มปิด (กันสุ่มซ้ำคนก่อนรู้ประวัติ) · ตัวเลขขึ้น "–" ไม่ใช่ 0
- เปลี่ยนห้อง/โหมด/ปิดหน้ากลางการหมุนหรือรอข้าม → `epoch` ยกเลิกทั้งหมด ไม่เขียนประวัติห้องผิด (เทสต์ "changing room while spinning")
- ข้อความผล/ประกาศสร้างจาก id ตอน render ไม่เก็บชื่อเต็มเป็นสตริงค้าง → T-45 เปิดซ่อนชื่อทีหลังแล้วชื่อหายทันที: ใช้ตัวแปร `hide` (ตอนนี้ `false`) ที่เดียวใน Random.tsx + `shortLabel/fullLabel`
- ผลจับกลุ่มเก็บเป็น `Student[][]` ใน state (ไม่เก็บถาวร)

## Mutation (ลองจริง แล้วคืนโค้ด)
1. n = ความยาวประวัติแทน N − m → ล้ม 2 (random-model + hr-random "drawn = N - m")
2. เสียงติ๊งดังเสมอ (ถอด `tick &&`) → ล้ม 1 ("is off at first…")
3. ถอดลำดับตรวจห้องว่างก่อน (RS-07) → ล้ม 1 ("an empty room says so…")
4. ถอด `epoch` ใน step/finish → **ไม่ล้ม** เพราะ `clearTimers()` ตอนเปลี่ยนห้องหยุดตัวจับเวลาอยู่แล้ว (epoch เป็นชั้นสำรอง; เทสต์ race ผ่านด้วยเหตุผลนี้ — ไม่ได้พิสูจน์ epoch เดี่ยว ๆ)
