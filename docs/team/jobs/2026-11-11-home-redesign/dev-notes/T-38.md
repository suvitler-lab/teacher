## ทำอะไร
- hero (`ScanHero.tsx`): ชื่องาน 2 บรรทัด · "รับแล้ว x จาก y คน" (aria-live=off) · วงแหวน % role=img (ไม่ทราบ = "ไม่ทราบ" ไม่ใช่ 0) · pill ห้อง/วิธี/วันที่รับ · ชิปครบกำหนด · ออนไลน์+รอส่ง · ป้ายเครื่องยิง · ปุ่ม ปรับการ์ด/ฉายจอ/จบรอบ (ปลายทางเดิม)
- เลย์เอาต์ 2 คอลัมน์ 1.7fr/1fr ≥1000px, คอลัมน์เดียวด้านล่าง; แผงข้าง = สแกนล่าสุด → ยังไม่ส่ง → รอส่งขึ้นระบบ
- AC-65: แถวสแกนล่าสุดมีไอคอน+คำวิธีรับ (hid/camera/manual) จาก `opMethods` ใน state.ts (ไม่แตะ op จริง); พิมพ์คะแนนทับยังคงวิธีเดิม; เลิกทำคืนวิธีเดิม
- AC-66: การ์ด `unsent` (ScanSide.tsx) อ่านอย่างเดียว ≤12 ชิป + "และอีก n คน" · "ทุกคนส่งครบแล้ว" · พับบนจอแคบ
- AC-67: การ์ดผลต่อท้าย "· รอส่งขึ้นระบบ" เมื่อออฟไลน์+op ยังอยู่ในคิว · มุมช่อง cloud-upload/cloud-x · การ์ดคิวในแผงข้าง
- AC-60: แถบค้าง "คะแนนเต็มถูกแก้ไข" + [เริ่มรอบใหม่] (`restartRound`) จาก assignment ที่โพลล์หรือ ack `full_score_changed`
- AC-62/64: ช่อง "?" เมื่อไม่ทราบ · ลูกศรย้ายช่อง (roving tabindex) · ช่องล่าสุดขอบหนา+ป้าย "ล่าสุด" · ห้อง 0 คนมีข้อความ+[นำเข้านักเรียน] · ช่องเว้น 8px
- AC-58: การ์ดเลือกคน (เลขซ้ำ) เป็น role=alert · AC-69: แถบกล้องเพิ่ม "เครื่องยิง/พิมพ์เลขที่ใช้ได้ตามปกติ", วิวกล้อง ≤240px · AC-56: inputMode=numeric
- AC-71: `SCAN_META`/`SCAN_LOCKED_TEXT` ใน ScanSide.tsx (meta.ts ไม่ใช่ไฟล์ของ task นี้)
