## ที่แก้ (เดิม -> ใหม่)
- ชื่อการ์ดของ ก: "งานที่กำลังเก็บ"->"ความคืบหน้ารายห้อง", "ครบกำหนดวันนี้/พรุ่งนี้"->"ครบกำหนด", "ใครไม่มาวันนี้"->"ไม่มาวันนี้" (ทุกข้อที่ใช้ heading; R-3306 ปุ่มเลื่อน)
- .pg-cols สามคอลัมน์ -> ก ใช้ .hma-grid/.hma-side: ยืนยัน "การ์ดเดียวที่เปิด = การ์ดเดียว" + ลำดับการ์ดตามค่าที่บันทึก
- "สแกนห้องนี้" (การ์ดงานเดิม) -> ปุ่ม "สแกนรับ <งาน> <ห้อง>" ของโครง ข (ค้าง/ยังไม่ส่ง >0, ไม่ขึ้นเมื่อปีเก่า) ตั้งโครงด้วย saveAppearance
- ยังไม่ส่ง/รอตรวจ ต่อห้อง + 6/8 · ยกเว้น 2 -> ก: progressbar + "รอตรวจ/ค้าง"; ข: ปุ่ม ค้าง/รอตรวจ + .nums "6/8 · ยกเว้น 2" (rate ตาม BR-03 = ส่ง/(ส่ง+ค้าง) จึงให้ missing:2 ในข้อ progressbar)
- ควรปิดรับ -> แถวเลยกำหนดในลำดับงานวันนี้ + ปุ่ม "ปิดรับงานนี้" (ไป /gradebook)
- ครบกำหนด: ก ไม่แสดงชื่อเด็กบนจอ (AC-19 ใช้ปุ่มคัดลอก LINE) -> ยืนยันจำนวนต่อห้อง + ไม่มีชื่อ + ข้อความคัดลอกมีชื่อ (ต้องมีงานครบกำหนดวันนี้ใน fixture)
- การ์ด "ต้องทำตอนนี้" -> แถวใน .hma-tl (failed มาก่อน, แถวห้องที่ยังไม่เช็คหลังเลยเวลาสาย, ว่าง = "เคลียร์ครบแล้ว เยี่ยมมาก")
- ซ่อนชื่อ/ไม่มา: ใช้ชื่อเล่น (shortName) ไม่ใช่ "เด็ก0 ทดสอบ"
