ใช้ได้ส่วนใหญ่ ชัดพอ (props เล็ก, layout ไม่คำนวณเอง, เส้นทางปุ่มผ่าน `runTodayGo`) จุดที่ควรเขียนเพิ่มใน `meta.ts` ก่อนเริ่ม:

5. **ห้องที่ไม่มีใน payload** (เช่นเทอมอื่น ห้องไม่มีงาน) ได้ `rate: null`, `att: null` — เขียนให้ชัดว่า null = "—" ไม่ใช่ 0% และ `att: null` ≠ "ยังไม่เช็ค"

7. **ป้าย level** (ต้องดู/ควรทำ/ว่างค่อยทำ) กับสี: model ให้แค่ `level` · ระบุ token สีของแต่ละระดับไว้ที่เดียวจะได้ 3 โครงตรงกัน
