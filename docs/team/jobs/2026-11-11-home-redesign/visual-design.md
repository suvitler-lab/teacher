# Visual design: หน้าหลักใหม่ 3 โครง + ชุดหน้าตา 3 ธีม

โดย Web Designer · 2026-11-11 · อ้างอิง `ux.md`, `requirements.md` (AC-01–43, BR-01–11), `design/draft.html` (Gate R ที่อนุมัติ)

## แนวทาง

- อารมณ์ (Gate 0): "ทำทุกแบบ เลือกธีมได้ที่ตั้งค่า" → 3 ธีม คนละบุคลิกจริง แต่ **โครงสร้างและตำแหน่งปุ่มเหมือนกันทุกธีม**
  - มืออาชีพ — สะอาด แม่น ไว้ใจได้ (กรมท่า + ฟ้าน้ำทะเล)
  - อบอุ่น (ค่าเริ่มต้น) — นุ่ม เป็นกันเอง มีชีวิต (ส้มอิฐ + ครีม + เมนูไม้เข้ม)
  - สดใส — สนุก ชัด กล้า (เหลือง + น้ำเงิน ขอบหมึกแบบสติกเกอร์)
- จุดเด่น 1 จุดต่อหน้า: ก = ตัวเลขใหญ่ "เหลือ N อย่าง" ใน hero สี · ข = วงแหวน % ต่อห้อง · ค = การ์ดโฟกัสสี
- แบรนด์เดิมที่คง: โลโก้ติ๊กในสี่เหลี่ยม · ชื่อเมนู 8 หน้าและลำดับกลุ่ม (D22) · ชื่อตัวแปร token เดิม
- ค่าเริ่มต้น (Gate 1): โครง ก + ธีมอบอุ่น · โหมด = ค่า `theme` เดิมของครู (ไม่เคยตั้ง = ตามเครื่อง)

## Design tokens

ไฟล์จริง: `src/styles/tokens.css` (Front-End ย้ายเข้าตอนทำหน้าเว็บ — รอบนี้ไม่แตะ `src/`) · ค่าทุกตัวอยู่ใน `design/preview.html` บล็อก `[data-theme=…][data-mode=…]` คัดลอกไปได้ตรง ๆ

โครงที่เสนอใน `tokens.css`: `:root[data-skin="pro|warm|playful"]` (ชุดหน้าตา) × `:root[data-theme="light|dark"]` (ตัวแปรเดิมของโหมด) — **ไม่ใช้ชื่อ `data-theme` สำหรับธีมสีในแอปจริง** เพราะ `data-theme` ใช้กับสว่าง/มืดอยู่แล้ว (ใน preview ใช้ `data-theme`/`data-mode`)

## ตาราง contrast ที่วัดแล้ว

วิธีวัด: สคริปต์ใน browser อ่านสีที่ **คำนวณจริง** (`getComputedStyle`, รวมพื้นโปร่ง/`color-mix`) ของข้อความที่มองเห็นทุกชิ้น · หน้าหลัก ก/ข/ค (ปกติ ซ่อนชื่อ ออฟไลน์ วันว่าง) + ตั้งค่า + สแกน + สมุดคะแนน × 6 ธีม-โหมด ที่ iPad นอน · เกณฑ์ 4.5:1 (ตัวใหญ่ ≥ 24px หรือ ≥ 18.6px หนา = 3:1)

| ผล | ค่า |
|---|---|
| ข้อความต่ำกว่าเกณฑ์ | **0 จุด** ทั้ง 6 ชุด (PASS) |
| ไอคอนบน `--fill-success` (ux #3, วัดจริง) | สดใส สว่าง: ขาว 2.23 → `--on-success` #15142b **8.08** · สดใส มืด: ขาว 2.23 → #12112a **8.27** · มืออาชีพ มืด: ขาว 2.61 → #0a1120 **7.22** · อบอุ่น มืด: ขาว 2.52 → #1b1611 **7.12** · มืออาชีพ สว่าง ขาว **3.38** · อบอุ่น สว่าง ขาว **3.31** (≥ 3 ผ่านสำหรับไอคอน) |
| `--border-control` บน `--surface-2` (วัดจริง) | pro สว่าง 3.06 · pro มืด 3.97 · warm สว่าง 3.35 · warm มืด 3.60 · playful สว่าง 18.00 · playful มืด 4.97 |
| hero โครง ก ที่คอม 729px | สูง 180px (เป้า ≤ ~200) |
| ไอคอนโหนด timeline | เปลี่ยนจาก `--fill-*` เป็น `--text-success/warning/danger` (≥ 4.5 ทุกชุด — คู่ text/bg เดียวกับป้ายสถานะ) |
| `--border-control` บนการ์ด (ux) | pro 3.06 · warm 3.35 (ใกล้ขีด ห้ามอ่อนลง) · playful = หมึก #15142b |
| ค่าตัวอย่างจาก ux.md (คงเดิม) | ปุ่ม on-accent: pro 6.25 · warm 5.45 · playful 5.12 · hero-muted ≥ 6.4 |

สถานะไม่สื่อด้วยสีอย่างเดียว: ป้ายงาน "ต้องดู/ควรทำ/ว่างค่อยทำ" (คำ+ไอคอน) · เช็คชื่อ มา/สาย/ลา/ป่วย/ขาด มีไอคอน+คำ · แถบความคืบหน้ามี legend คำ + ตัวเลข · ห้องที่เลือก = ขอบ 3px + "กำลังดู" + caret · ปุ่มซ่อนชื่อ = ไอคอนตาปิด + คำ "ซ่อนชื่ออยู่" + `aria-pressed`
