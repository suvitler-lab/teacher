## ผลตรวจที่ UX ฝากไว้

1. **เลขเวอร์ชันแอป (P4):** `package.json` มี `"version": "0.1.0"` แต่ไม่ถูกส่งเข้าแอป (ไม่มี `define`/`VITE_*VERSION` ใน vite config หรือ src) และเลขนี้ไม่เคยขยับตามการปล่อย → แสดงแล้วอาจทำให้เข้าใจผิด · AC-237 ไม่แสดงเลข → SGQ1
2. **เกณฑ์สำรองค้าง:** `backupLine` (src/components/settings/SettingsCards.tsx:30) ใช้ `floor(วัน) > 7` = ค้างตั้งแต่วันที่ 8 · ไม่เคยสำรอง = ค้าง → BR-56 ใช้ตามนี้ ไม่เปลี่ยน
3. **ชื่อซ้ำ:** `sameName` (worker/routes/catalog.ts:264) = ตัดช่องว่างหัวท้าย + ตัวพิมพ์เล็ก เทียบเฉพาะ active → BR-53
4. **หน้าตาบันทึกล้ม:** ux.md:187–188 และ ux-settings §ความต่าง ถูกแทนด้วย D38 (เจ้าของงานตัดสิน 2026-11-11 · requirements.md บรรทัด 176, 184) = ค่าที่ซิงก์ รวมหน้าตา บันทึกล้ม/ออฟไลน์ ย้อนค่าเดิม + แจ้ง ไม่เข้าคิว → AC-215–AC-217 · BR-51
5. **ยังไม่ยืนยันจากโค้ด (ตามที่ ux ฝาก):** ค่าเริ่มต้น `sound_enabled`/`accept_student_code_scan` (A28) · `StartTermModal` focus trap ครบไหม (AC-232 ต้องผ่านไม่ว่าเดิมเป็นอย่างไร) · คีย์ซ่อนชื่อ 5 หน้ายังไม่มีในโค้ด (A27)

## ข้อจำกัดกลาง

- ส่วนที่ 1–9 ใช้ด้วย · **ไม่แตะ worker, `shared/*`** · **P1–P10 ไม่ต้องเพิ่ม endpoint (ไม่มี EP-ใหม่) และไม่มีคีย์ setting ใหม่ฝั่งเซิร์ฟเวอร์** · ค่าใหม่ทั้งหมด (ซ่อนชื่อ 5 หน้า · เสียงติ๊ง) = localStorage · ไม่ติดตั้ง package
- หมวด "หน้าตา" = AC-44 + BR-07 + BR-12 ที่อนุมัติแล้ว ไม่ออกแบบซ้ำ ที่นี่กำหนดเฉพาะตำแหน่ง (กลุ่มเครื่องนี้ หมวดแรก)
- สวิตช์ซ่อนชื่อใน privacy แก้ค่าของหน้าอื่น → ต้องตรวจ AC ซ่อนชื่อของทุกหน้าซ้ำ (หน้าหลัก · สแกน · เช็คชื่อ AC-101 · สุ่มชื่อ · คะแนน · รายงาน · นักเรียน) · หน้าใดยังไม่มีสวิตช์ในโค้ด สร้างคีย์ในทะเบียน BR-52 พร้อมกัน
- ข้อความที่เทสต์ล็อก (ux-settings §เทสต์เดิม) คงเดิม ยกเว้น "ข้อมูลพื้นฐาน" (แก้เทสต์คู่กัน) · iPad จริง/VoiceOver/ซูม 200% = NOT RUN จน Gate V · BR-10 ชนะ ux เรื่องเวลาแอนิเมชัน
