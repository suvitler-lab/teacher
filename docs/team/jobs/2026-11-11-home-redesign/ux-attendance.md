## ผู้ใช้และงานหลัก

- ครูคนเดียวหลายห้อง **ต้นคาบยืนหน้าห้องถือ iPad** เช็คชื่อ 30–45 คนให้เสร็จเร็ว มือเดียวหรือสองมือ ตาต้องกลับไปมองเด็ก · เน็ตโรงเรียนไม่แน่นอน · บางครั้งสะท้อนจอขึ้นทีวี (เด็กเห็นรายชื่อคนขาด)
- งานหลัก: (1) เปิดมาเห็นห้อง/วันที่ถูกต้องทันที (ห้องที่ดูล่าสุดจำไว้, วันนี้เป็นค่าเริ่มต้น) (2) แตะรายคน หรือ "มาทั้งห้อง" แล้วแก้เฉพาะคนที่ไม่มา (3) รู้ทันทีว่า "ยังเหลือใครที่ยังไม่ได้เช็ค" (4) มั่นใจว่าบันทึกแล้ว แม้ออฟไลน์ (5) ดูย้อนหลัง/แก้วันก่อนหน้าได้
- หลักออกแบบ: (ก) สถานะทุกอย่าง = ไอคอน + คำ + รูปทรง ไม่ใช้สีอย่างเดียว (ข) แตะแล้วเห็นผลทันที ไม่มีปุ่มบันทึก (ร่างในเครื่อง → ส่งเอง) (ค) ทุกอย่างผูกกับข้อมูลที่แอปมีจริง — ส่วนที่ต้องเพิ่มติดป้าย `ใช้ข้อมูลเดิม` / `งานถัดไป` (ง) ไม่เปลี่ยนการตัดสินเดิม: ปุ่ม 5 สถานะ ไม่มี "วนสถานะ" (D37) · แตะซ้ำ = ยกเลิก + เลิกทำ 5 วินาที (D39) · ฉายจอแสดงชื่อคนล่าสุดได้ มีสวิตช์ซ่อน (D38/D27) · ร่างในเครื่องไม่ถูกลบเงียบ ๆ

**จุดเด่นทางสายตา (ห้ามลด):** (1) hero สีของธีมกับ "เช็คแล้ว 38 จาก 45" ขนาด display (2) วงแหวนใหญ่ **แบ่งเป็น 5 ช่วงตามสถานะ** (ไอคอน/ตัวอักษรกำกับ + legend ตัวเลข ไม่ใช้สีอย่างเดียว) เติมค่าตอนเปลี่ยน ≤ 300ms · ส่วน "ยังไม่เช็ค" เป็นช่วงเส้นประ (3) แถบเลือกสถานะ 5 ปุ่มสูง ≥ 56px ไอคอน 24px + คำ ปุ่มที่เลือกเด่นชัด (ขอบหนา + พื้นเต็มสี) และ "มาทั้งห้อง" เป็นปุ่มเด่นแยกอีกสี (4) ช่องนักเรียนใหญ่ เลขที่ตัวหนา + พื้นสีตามสถานะ + ไอคอน (ขอบทึบ = เช็คแล้ว · ขอบเส้นประ = ยังไม่เช็ค) และช่องที่เพิ่งแตะมีขอบหนา `.hit` (5) เมื่อเช็คครบทุกคน: hero เปลี่ยนเป็นข้อความ "เช็คครบแล้ว · มา 43 · ขาด 2" พร้อมไอคอน circle-check ใหญ่ (ฉลองเล็กตามธีม ไม่แฟลช) (6) การ์ดข้างไม่เป็นกล่องขาวเรียบ: ใช้หัวการ์ดมีไอคอน+ตัวเลขนับ

## หน้าจอ A: เช็คชื่อ

**ลำดับข้อมูล (ลำดับ DOM = ลำดับ focus):** แถบบน → แถบแจ้ง (ย้อนหลัง · ก่อนเปิดปี · ไม่ตั้งเวลาคาบ) → การ์ดที่ต้องตัดสิน (ชนกัน · ต้องตรวจสอบ · ร่างที่อื่น) → **hero** → แถบสัปดาห์ (รายวันเท่านั้น) → **แถบเลือกสถานะ + มาทั้งห้อง** → (โหมดสแกน: ช่องรับเลข + ผลล่าสุด) → **กริดนักเรียน** → แผงข้าง → แถบบันทึกล่าง

| บล็อก | เนื้อหา | กดได้ |
|---|---|---|
| ชิปห้อง | ชื่อห้อง + จำนวนคน + เครื่องหมาย ครบ(circle-check)/บางส่วน(circle-half-2)/ยังไม่เช็ค(clock) | แตะ = เปลี่ยนห้อง (จำไว้) |

## ความสัมพันธ์กับหน้า "สุ่มชื่อ" (ไม่ออกแบบหน้าสุ่ม)

- ทางเชื่อมที่มีจริง: สุ่มชื่ออ่าน `GET /api/attendance?date=วันนี้&class` แล้วสุ่ม **เฉพาะ `present`+`late`** (ลา/ป่วย/ขาด/ยังไม่เช็ค ไม่ถูกสุ่ม) · ถ้าวันนี้ยังไม่มีแถวเลย → บอก "วันนี้ยังไม่ได้เช็คชื่อ" + ปุ่ม [ไปเช็คชื่อ] → `/attendance?class=` · ป้าย "มาเรียนวันนี้ x จาก y คน"
- ในหน้าเช็คชื่อ: เมื่อ ST-03 (ครบ) แสดงปุ่มรอง **[สุ่มชื่อเฉพาะคนที่มา (43)]** (P4) → `/random` · **ข้อจำกัดจริง:** สุ่มชื่อไม่อ่าน `?class` จาก URL (ใช้ห้องที่ตัวเองจำ) → ปุ่มพาไปหน้าสุ่มได้ แต่ห้องอาจไม่ตรง — ต้องแก้หน้าสุ่มเล็กน้อย (ไม่ใช่ API) · และ **รายคาบไม่ส่งผลต่อสุ่มชื่อ** (สุ่มอ่านรายวันเท่านั้น) → **คำถาม Q4**
- ตัวเลขที่ต้องตรงกัน: "มา x" ในสรุปเช็คชื่อ = present (+ late รวมใน "มาเรียน"); ตัวเลข "มาเรียน" ของสุ่มชื่อ = present+late ของวันนี้ — ใช้นิยามเดียวกัน

## การเข้าถึง (accessibility) ♿

**ลำดับ focus** (ตาม DOM ไม่ใช้ `order` CSS): ข้ามไปเนื้อหา → เมนู → แถบบน (ซ่อนชื่อ · ฉายจอ · ปรับการ์ด) → แถบแจ้ง/การ์ดตัดสิน → hero (ห้อง · วัน ‹ วัน › · แตะ/สแกน · รายวัน/คาบ) → แถบสัปดาห์ → **แถบสถานะ (radiogroup — Tab เข้าครั้งเดียว ลูกศรย้าย)** → มาทั้งห้อง → ช่องรับเลข (โหมดสแกน) → **กริดนักเรียน (Tab เข้า/ออกครั้งเดียว ลูกศรย้ายช่อง Enter/Space = แตะ)** → แผงข้าง → แถบบันทึก · แผ่น/กล่อง: ย้าย focus เข้าข้างใน วนใน · Esc ปิด · คืน focus ปุ่มที่เปิด · หลังเลิกทำ/ยืนยัน/แตะชิปเลขที่ → focus ที่ช่องนั้น (ไม่ดึงแป้นพิมพ์บนจอสัมผัส)

**aria-live (ประกาศการเปลี่ยนสถานะ):** (ก) **ทุกแตะ** ประกาศ `role=status` polite 1 ครั้ง "เลขที่ 7 สมหญิง — มา" / "ยกเลิกการเช็คเลขที่ 7" (ซ่อนชื่อ = ไม่มีชื่อ) — **ใหม่:** ของเดิมมีเฉพาะผลสแกนและชิปบันทึก · แตะรัว ๆ ให้รวมประกาศล่าสุดเท่านั้น (ไม่เข้าคิว) (ข) มาทั้งห้อง ประกาศครั้งเดียว "ให้มา 31 คน เลิกทำได้ไม่กี่วินาที" (ค) ชิปบันทึก `role=status`: "บันทึกแล้ว 08:42" / "ออฟไลน์ เก็บในเครื่อง" (ง) ผิดพลาด/ต้องตัดสินใจ (ชนกัน, ต้องตรวจสอบ, ก่อนเปิดปี) = `role=alert` (จ) ตัวเลข "เช็คแล้ว x จาก y" `aria-live=off` ไม่ท่วม · วงแหวน `role=img` label "มา 29 สาย 2 ลา 1 ป่วย 0 ขาด 2 ยังไม่เช็ค 11 จาก 45 คน"

**เวลาจำกัดของเลิกทำ (WCAG 2.2.1):** 5 วินาที ตาม D39 · แก้ภายหลังได้เสมอ (แตะใหม่) · เสนอ: หยุดนับเมื่อ hover/focus toast

**contrast/สี:** ข้อความ/พื้นช่อง 5 สถานะ + รอเลือก ≥ 4.5:1 และไอคอน/ขอบ ≥ 3:1 ทั้ง 3 ธีม × สว่าง/มืด (Web Designer วัดทุกคู่ แล้วรายงานตารางแบบ visual-design หน้าสแกน) · `--att-*` ใช้เป็นพื้น/ขอบ ตัวอักษรใช้ `--text-*` คู่กัน · ไม่สื่อด้วยสีอย่างเดียว: ทุกสถานะ = ไอคอน + คำ · ยังไม่เช็ค = เส้นประ · รอเลือก = ขอบหนา + ⚠ · วงแหวนมี legend ตัวเลข
