## T-06 ตัวสลับเมนู (รอบออกแบบที่ 2 · 2026-11-11)

ข้อมูลเมนูจากบล็อก JSON ท้าย `menu-proposal.md` (ไม่แก้ไฟล์นั้น)

- แถวใหม่ในแถบควบคุม: **เมนู: ก คงเดิม · ข ลด · ค เพิ่ม · ง แนะนำ** (เริ่ม = ก) + ข้อความ 1 บรรทัดว่าต่างจากเดิมอย่างไร
- สลับแล้วเปลี่ยนจริง 3 ที่: เมนูซ้าย (iPad/คอม) · แถบล่างมือถือ 5 ช่อง (เหมือนกันทุกทางตามข้อเสนอ) · แผ่น "เพิ่มเติม" (แยกกลุ่ม มีหัวกลุ่ม)
- ทาง ง = ก + "ตารางสอน" ต่อจากหน้าหลัก (9 รายการ) — แผ่นอธิบายบอกว่าโผล่เมื่อหน้าสร้างเสร็จ
- เมนูซ้ายมี **ป้ายกลุ่มเป็นตัวหนังสือ** (วันนี้ / ในห้องเรียน / ตรวจงาน / จัดการ, 13px สี `--rail-label`) แทนเส้นคั่นเดิม — ทุกทางเหมือนกัน เพื่อเทียบกลุ่มได้ · เปลี่ยนหน้าตาเมนูจากที่อนุมัติเล็กน้อย (เส้น → ตัวหนังสือ) ⇒ ถามเจ้าของงานที่ Gate เมนู
- ป้าย "ใหม่" บนรายการที่เพิ่ม (ตารางสอน บัตร QR สำรองข้อมูล) · ป้าย "รวม" บน "คะแนนและรายงาน" (ข)
- รายการที่ไม่มี mockup → แผ่นอธิบาย: หน้านี้คืออะไร · มีอยู่แล้ว / หน้าใหม่ (แตะหลังบ้าน) / ลิงก์ลัด (ไม่แตะหลังบ้าน) · ปิดด้วยปุ่ม/Esc/แตะพื้นหลัง โฟกัสกลับปุ่มเดิม
- ทาง ข: สมุดคะแนนมีปุ่มสลับ "คะแนน | รายงาน" ที่หัวหน้า (รายงาน → แผ่นอธิบาย)
- เมนูซ้ายแยกส่วนเลื่อน (`.rail-list`) — โลโก้กับ "ออกจากระบบ" อยู่กับที่ · ถ้าล้น: เงาจาง + ชิป "มีต่อ ▾" ด้านล่าง / เงาด้านบนเมื่อเลื่อนลงแล้ว
