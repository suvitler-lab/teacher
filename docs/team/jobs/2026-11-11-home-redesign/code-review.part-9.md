### ตรวจแล้วไม่พบปัญหา

- **ตัวเลข BR-13/14** — `roundNumbers`: ส่งแล้ว = `status === "submitted"` (รวมที่ไม่มีคะแนน) · ยังไม่มีคะแนน ⊂ ส่งแล้ว · ยังไม่ส่ง = ที่เหลือที่ไม่ใช่ยกเว้น (void/ไม่มีแถว) · วงแหวน `percentOf(submitted, submitted+missing)` → ตัวอย่าง 26/31 = 84% (test:71 ผ่าน) · hero T-38 ใช้ `percentOf(seat.submitted, seat.counted)` กฎเดียวกัน · `nextRoom` ใช้ `roundNumbers` ตัวเดียวกัน x/y จึงไม่นับยกเว้น
- **รายการรอส่ง** — `effSubOf(aid)` ใช้ได้แม้ไม่มี `session` (หน้าสรุป) ต่างจาก `effSub` เดิมที่คืนค่าของ server อย่างเดียวตอน session = null (ต้นเหตุที่สรุปเดิมไม่นับรายการรอส่ง) · op `void` → undefined → นับเป็นยังไม่ส่ง (test:145) · ไม่นับซ้ำ เพราะได้ 1 สถานะต่อ 1 คน
- **ไม่ทราบ** — `known = box.aid === s.assignmentId && status === "ready"` · ไม่รู้ → วงแหวน "ไม่ทราบ", ไม่มีกลุ่ม, ไม่มีปุ่มห้องถัดไป, live region ว่าง (test:165) · คำตอบที่ยังค้างอยู่ตอนจบรอบยังเขียนลงได้ เพราะ `roundAid()` ใช้ `ended` แทน
