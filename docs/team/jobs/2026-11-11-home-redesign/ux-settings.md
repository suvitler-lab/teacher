## 👤 ความปลอดภัยและข้อมูลส่วนบุคคล

- **ไฟล์สำรอง** (ชื่อเด็ก รหัส คะแนน ไม่เข้ารหัส): กล่องเตือนก่อนดาวน์โหลด ไม่โทษครู ไม่ส่งไปที่ไหนเอง
- **รหัสผ่าน:** `type=password` · `autocomplete` ถูกชนิด · ล้างค่าหลังสำเร็จ (:624) · ไม่อยู่ใน audit
- **ชื่อเด็กใน "แก้ไขล่าสุด"/ประวัติ:** ซ่อนตามสวิตช์ (P2) · ฉายจอ: หน้าตั้งค่าปิดการเขียนทั้งหมด · อีเมลครูซ่อนเป็น "ซ่อนอยู่" ตอนฉายจอ · QR token ไม่แสดงในหน้านี้


## ♿ การเข้าถึง (ตาม `checklists/accessibility.md`)

- **contrast** ข้อความ ≥ 4.5:1 · ไอคอน/ขอบสวิตช์/focus ≥ 3:1 ทั้ง 3 ธีม × สว่าง/มืด · สถานะ = ไอคอน+คำ ไม่ใช้สีอย่างเดียว
- **สวิตช์:** `role=switch` + `aria-checked` + ป้าย + ข้อความ "เปิด/ปิด" ที่มองเห็น · พื้นที่กดทั้งแถว ≥ 44px · segmented = `role=radiogroup`
- **เป้าแตะ ≥ 44px ทุกอุปกรณ์รวมคอม** (ปุ่ม ↑↓ เมนูหมวด ปุ่มสี ช่องเวลา ⋮ ช่องติ๊ก) · ปุ่มติดกันห่าง ≥ 8px
- **aria-live:** ผลบันทึก `role=status` · error ระดับหน้า `role=alert` · ตัวนับ "แก้ไขแล้ว n รายการ" · ผลตรวจเครื่อง · "เพิ่มห้อง ป.6/3 แล้ว" · สลับหมวดย้าย focus ไปหัว `h2`
- **คีย์บอร์ด/focus:** ลำดับ หัว → หมวด → เนื้อหา → แถบบันทึก · `aria-current` ที่หมวด · ลูกศรขึ้นลงในรายการหมวด · แท็บ ห้อง/วิชา/ภาคเรียน = `role=tablist` · Esc ปิดโหมดแก้ไขแล้วคืน focus · กล่องยืนยัน = focus trap (`Dialog`) เริ่มที่ `ยกเลิก` (ล้างข้อมูล = ช่องรหัสผ่าน) ปิดแล้วคืน focus · error ผูกช่อง `aria-invalid`+`aria-describedby`
- **reduced-motion:** `.spin` เหลือไอคอนนิ่ง+คำ · การเปลี่ยนหมวด/กล่อง ≤ 250ms ปิดเมื่อ reduced · ซูม 200% ไม่ทับ
