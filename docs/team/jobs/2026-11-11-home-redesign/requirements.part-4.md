## User stories

- US-14: ในฐานะครู ฉันต้องการเปิดหน้าแล้วเห็นห้องและวันที่ถูกต้อง พร้อมภาพรวมวัน/สัปดาห์/เดือน เพื่อรู้ทันทีว่าห้องนี้เช็คไปถึงไหน
- US-15: ในฐานะครูที่ยืนหน้าห้อง ฉันต้องการแตะรายคน "มาทั้งห้อง" หรือสแกนบัตร แล้วแก้เฉพาะคนที่ไม่มา เพื่อเช็คชื่อ 30–45 คนเสร็จในไม่กี่นาที
- US-16: ในฐานะครู ฉันต้องการรู้ว่าบันทึกแล้วหรือยัง แม้เน็ตหลุดหรือแก้ชนกับอีกเครื่อง เพื่อไม่ต้องเช็คซ้ำ
- US-17: ในฐานะครูที่สะท้อนจอ ฉันต้องการซ่อนชื่อในหน้านี้ ฉายจอ ไปสุ่มชื่อต่อ และใช้ได้ทุกอุปกรณ์/แป้นพิมพ์/VoiceOver

## กฎธุรกิจ

### BR-19 ตัวเลขเช็คชื่อ (เดิม ห้ามเปลี่ยน)

นับเฉพาะนักเรียน active ของห้อง (ทั้งวันนี้และวันเก่า D11) · ต่อสถานะ = จำนวนช่องที่เป็นสถานะนั้น (ร่างในเครื่องทับข้อมูลระบบ) · เช็คแล้ว = ผลรวม 5 สถานะ · รอเลือก (ชนกัน) ไม่นับในสถานะใด · ยังไม่เช็ค = ทั้งหมด − เช็คแล้ว − รอเลือก · มาเรียน = มา + สาย · % = `attendancePercent` = (มา + สาย) ÷ เช็คแล้ว ปัดแบบ `percentOf` · ห้อง ครบ/บางส่วน/ยังไม่เช็ค = `attendanceProgress(เช็คแล้ว, ทั้งหมด)` · ฉายจอ % = (มา + สาย) × 100 ÷ ทั้งหมด ปัด

ตัวอย่าง: 45 คน มา 29 สาย 2 ลา 1 ป่วย 0 ขาด 2 รอเลือก 0 → เช็คแล้ว 34 · ยังไม่เช็ค 11 · "มาเรียน 31 จาก 45 คน (91% ของที่เช็คแล้ว)" (3100 ÷ 34 = 91.18 → 91) · บางส่วน · ทีวี "มาแล้ว 31 จาก 45" แถบ 3100 ÷ 45 = 68.9 → 69% · ห้อง 32 คนเช็ค 1 คน → บางส่วน (ไม่ใช่ครบ) · รอเลือก 2 → ยังไม่เช็ค 9

### BR-20 การบันทึก (เดิม ห้ามเปลี่ยน)

ทุกแตะเขียนร่างในเครื่องก่อน แล้วส่งเอง ~0.6 วิ ("มาทั้งห้อง" รอ 4.5 วิ เพื่อเลิกทำ) ผ่าน EP-08 · แตะซ้ำ = `status:"none"` (D39) · 409 `conflict` → รอเลือก · 409 `epoch_changed` / 422 `not_in_class` / `before_school_year` → ต้องตรวจสอบ ไม่ลบ · ลำดับชิปบันทึก (ข้อแรกที่จริง): ต้องตรวจสอบ > ชนกัน > บันทึกไม่สำเร็จ > กำลังบันทึก > มีรอส่ง (ลองซ้ำอยู่หรือออฟไลน์ → "ยังไม่ได้ส่ง n · ลองใหม่" มิฉะนั้น "รอส่ง n") > ยังโหลดไม่เสร็จ (ไม่แสดง) > ออฟไลน์ > บันทึกแล้ว · ตัวอย่าง: ออฟไลน์ รอส่ง 5 → "ยังไม่ได้ส่ง 5 · ลองใหม่" · ต้องตรวจสอบ 1 + รอส่ง 3 → "ต้องตรวจสอบ 1" · ไม่มีค้าง ออนไลน์ ส่งเมื่อ 08:42 → "บันทึกแล้ว 08:42"

### BR-21 การ์ด "เดือนนี้" (ใหม่)

ช่วง = วันที่ 1 ของเดือนของวันที่ที่ดูอยู่ ถึง min(วันสุดท้ายของเดือน, วันนี้) ไม่ก่อนวันเปิดปี · เฉพาะเช็คชื่อรายวันของห้องนี้ · เฉพาะวันที่เช็คแล้ว > 0 · % เดือน = Σ(มา + สาย) ÷ Σเช็คแล้ว (รวมก่อนหาร แบบ D24) ปัด `percentOf` · % ต่อวัน = (มา + สาย) ÷ เช็คแล้ว ของวันนั้น · ตัวอย่าง 3 วัน: (29+2)/33 = 94% · (30+0)/32 = 93.75 → 94% · (25+1)/31 = 83.9 → 84% · เดือน (31+30+26) ÷ (33+32+31) = 8700 ÷ 96 = 90.6 → **91%** (ถ้าเฉลี่ย % รายวัน = 90.7 → ก็ 91 แต่ต้องคิดแบบรวมก่อนหาร) · "เช็คแล้ว 3 วัน"

### BR-22 สแกนเช็คชื่อ มา/สาย (เดิม ห้ามเปลี่ยน)

สาย เมื่อ วันที่ดูอยู่ = วันนี้ (เวลาไทย) และมีเวลาเกณฑ์ และนาทีปัจจุบัน > เกณฑ์ · เกณฑ์รายวัน = `late_after` (ไม่ตั้ง = 08:30) · รายคาบ = เวลาเริ่มคาบใน `period_times` ไม่ตั้ง = ไม่รับสแกน · วันที่ผ่านมา = "มา" เสมอ · เด็กต้องอยู่ห้องที่เลือก · ตัวอย่าง `late_after` 08:30: สแกน 08:30 → มา · 08:31 → สาย · ดู 5 พ.ย. แล้วสแกนวันที่ 12 → มา · คาบ 3 เริ่ม 10:40 สแกน 10:45 → สาย

### BR-23 ข้อความ "เปลี่ยนจาก … เป็น …" และประกาศทุกแตะ (ใหม่)

สถานะเดิม = ร่างในเครื่องถ้ามี ไม่งั้นข้อมูลระบบ · แสดง "เปลี่ยนจาก <เดิม> เป็น <ใหม่>" เมื่อเดิมมีสถานะ และ ≠ ใหม่ (แตะหรือสแกน) · เดิมยังไม่เช็ค → แค่ "<ใหม่>" · เดิม = ใหม่ ด้วยการแตะ = ยกเลิก (D39 ไม่ใช่ข้อความนี้) · การเขียนเหมือนเดิมทุกกรณี · ซ่อนชื่อ = ไม่มีชื่อ · ตัวอย่าง: ขาด → สแกน 08:13 → "สมชาย · มา 08:13 · เปลี่ยนจาก ขาด เป็น มา" · มา → แตะด้วย "สาย" → "เลขที่ 7 สมหญิง — เปลี่ยนจาก มา เป็น สาย" (ซ่อนชื่อ: "เลขที่ 7 — เปลี่ยนจาก มา เป็น สาย") · ยังไม่เช็ค → "เลขที่ 8 สมชาย — มา"
