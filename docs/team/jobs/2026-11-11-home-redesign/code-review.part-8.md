#### R-4703 focus กลับปุ่ม Excel แย่ง focus จากช่องคะแนนที่ครูกำลังพิมพ์ → บันทึกค่าที่พิมพ์ไม่ครบ — 🔄 ข้อมูล (AC-145 × AC-130) · `src/pages/Gradebook.tsx:138`

- สถานการณ์: กด "ส่งออก Excel" (โหลดรายงานทั้งเทอม + สร้างไฟล์ ใช้เวลาหลายวินาทีบนเน็ตโรงเรียน) → ระหว่างรอ ครูแตะช่อง W1 เลขที่ 3 พิมพ์ "1" ตั้งใจจะพิมพ์ "10" → ไฟล์เสร็จพอดี → focus กระโดดไปปุ่ม Excel → ช่อง blur → บันทึก **1** (ค่าถูกต้องตาม BR-33 จึงไม่มีอะไรเตือน) และ "0" ที่พิมพ์ต่อไปตกที่ปุ่ม
