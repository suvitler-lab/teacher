# dev-notes · Front-End · gb-2

## ทำอะไร
1. เลิกพับกลุ่มอัตโนมัติ: ลบ `defaultCollapsed`/`oneMonthBefore`; `isCollapsed(key, overrides)` พับเฉพาะที่ครูพับเอง (สถานะพับเก็บในหน่วยความจำเท่านั้น ไม่เคยเก็บใน localStorage จึงไม่มีอะไรต้องล้าง)
2. คำสั่งเพิ่มของเจ้าของงาน: ค่าเริ่มต้น = "ไม่จัดกลุ่ม" · คีย์ localStorage เปลี่ยนเป็น `ngankrob.gb.groupMode.v2` (ค่าเก่าจาก gb-1a แยกไม่ออกว่าครูเลือกเองหรือไม่ จึงไม่อ่าน) · โหมดตามประเภท/เดือนยังเลือกได้
3. แตะ/Enter/Space ที่ช่อง "รวม {กลุ่ม}" ของนักเรียน → กางกลุ่ม เลื่อนให้เห็น และเปิดช่องกรอกคะแนนของนักเรียนคนนั้นในงานแรกของกลุ่ม (ที่แสดงอยู่) · aria-label/title "แตะเพื่อกางและแก้คะแนน" · ช่อง td มี `data-aid`/`data-sid`
4. จอคอม (CSS): ตารางไม่ยืด (เอา `min-width:100%` ออก ตารางชิดซ้าย) · name-col เป็น border-box กว้าง clamp(10.7rem,15vw,15.2rem) · ที่เลื่อนแนวตั้งที่เดียว: เมื่อเป็นเมาส์ (hover+fine) คำนวณ max-height ของตารางให้พอดีจอ หน้าไม่เลื่อน (iPad/จอสัมผัสใช้ CSS เดิม) · โหมดจัดกลุ่ม: หัว "สะสม" เป็น rowSpan=2 ไม่มีช่องว่างเหนือสะสม

## ที่ต่างจากหน้าตา "เดิมก่อน gb-1a" ที่ยังเก็บไว้
ล็อกชื่อ/สะสม, เงาขอบ, แถบย่อ+ปุ่มกระโดด, เมนูคอลัมน์, เมนูทำทั้งห้อง, ปุ่มตา ≥44 บนจอสัมผัส, หน่วย rem, ความกว้างคอลัมน์คงที่ 7.6rem (เดิมยืดเต็มความกว้าง), ชื่องานในหัวตาราง 2 บรรทัด (เดิมบรรทัดเดียวตัดด้วย …). ยังไม่ได้ย้อนหัวคอลัมน์ให้เรียบเท่าเดิมทุกจุด — ถ้าต้องการให้ย้อนอีก ให้แจ้งเป็นงานต่อ

## รอบแก้ 2 (จอเตี้ยบนโน้ตบุ๊ก)
เฉพาะ `@media (min-width:1100px) and (hover:hover) and (pointer:fine)` (จอสัมผัส/แคบไม่เปลี่ยน; แถวสถิติย้ายเข้าแถวตัวกรองโดยบนจอแคบยังขึ้นบรรทัดเต็มเหมือนเดิม):
- ชื่อหน้า + แถบห้อง + ปุ่มภาคเรียน/สร้างงาน อยู่แถวเดียว (.uh เป็น display:contents), ซ่อนบรรทัดย่อยซ้ำ, margin บนหน้าติดลบเล็กน้อย
- สถิติ (งาน/อัตราส่ง/รอตรวจ/ค้างส่ง) เข้าแถวตัวกรอง · แถบงาน (ทำทั้งห้อง) + minimap/ปุ่มกระโดด อยู่แถวเดียว (.gb-bar2 ห่อ GradebookNav)
- หัวคอลัมน์งานบรรทัดเดียว (ตัดด้วย … ชื่อเต็มอยู่ใน title) · ซ่อนบรรทัดคำแนะนำท้ายตารางเมื่อจอสูง ≤860px (ยังมีสัญลักษณ์/legend)
- ความสูงแถวไม่เปลี่ยน (51px ที่ 16px) ตัวอักษรไม่ย่อ
- วัด (browser, ฟอนต์ 16, ไม่จัดกลุ่ม, 19 งาน; แถวที่เห็นเต็มแถว): 1536x729 = 8 แถว · 1280x720 = 7 แถว (3 งาน = 8) · 1920x1080 = 15 แถว · ทุกขนาด: แถบเลื่อนแนวตั้งที่เดียว, หน้าไม่เลื่อน, ไม่เลื่อนแนวนอน, ข้อความ <13px = 0
- 820x1180 ที่ 18: เลย์เอาต์เดิม 7 แถว ไม่เลื่อนแนวนอน ข้อความ <13 = 0; 1180x820 ที่ 18: 7 แถว (ที่ 24px หน้าเลื่อนเหมือนก่อนหน้า) · ไม่ได้จำลอง coarse
