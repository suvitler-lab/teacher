## การเข้าถึง (accessibility) ♿

- **โครงตาราง (ก/ข วันสัปดาห์):** `role="grid"` พร้อม `role="rowheader"` (วัน) `role="columnheader"` (คาบ+เวลา) และ `role="gridcell"` · ทุกช่องมี `aria-label` ประโยคเต็ม: "วันพุธ คาบ 4 12:30 ถึง 13:30 คณิตศาสตร์ ป.6/3" · กิจกรรม: "วันพฤหัสบดี คาบ 6 14:30 ถึง 15:30 กิจกรรม ลูกเสือ" · ว่าง: "วันพุธ คาบ 3 ว่าง ปุ่มเพิ่มคาบ" · เก็บแล้ว: "…คณิตศาสตร์ ป.6/3 ห้องเก็บแล้ว" · ตอนนี้: ต่อท้าย "กำลังเรียนอยู่ตอนนี้" · แถบพัก "พักกลางวัน 11:30 ถึง 12:30" (`role="row"` คั่น/ ไม่ focus) · ข (แกนเวลา): สร้างเป็นรายการ DOM ตามวัน→เวลา (อ่านเรียงถูก) แล้วจัดตำแหน่งด้วย CSS ไม่ใช้ absolute ที่ทำให้ลำดับอ่านเพี้ยน · ค: `<ul>` รายการคาบ ไม่ใช่ grid
- **ลำดับ focus:** ข้ามเมนูข้าง → หัวหน้า (ชื่อภาค → ตั้งเวลาคาบ → พิมพ์ → ⋯) → แบนเนอร์/ป้ายสถานะ (ถ้ามี) → ตาราง (1 จุด Tab เข้าไป ลูกศรเดินในตาราง — roving tabindex) → สรุป → ปุ่มคัดลอก/ล้าง · ในแผ่น: ปิดล้อม focus · ช่องแรก = ชนิด (หรือช่องแรกที่ผิด) · เปิดแผ่นแล้วเมื่อปิด โฟกัสกลับช่องเดิม (แม้หลังลบ → ช่องว่างตำแหน่งเดิม)
- **แป้นพิมพ์:** ลูกศร = ช่อง ←→↑↓ (ก: ซ้าย/ขวา=คาบ บน/ล่าง=วัน; ข: บน/ล่าง=คาบ ซ้าย/ขวา=วัน) · Home/End = ต้น/ท้ายแถว · Ctrl+Home/End = ช่องแรก/สุดท้าย · Enter/Space = เมนูช่อง (มีคาบ) หรือเปิดแผ่นเพิ่ม (ว่าง) · Delete = ลบคาบที่โฟกัส (มี toast เลิกทำ ไม่ถาม) · Ctrl/⌘+Z = เลิกทำ · Esc = ปิดเมนู/แผ่น · Tab ออกจากตาราง · ทุกอย่างทำได้โดยไม่ใช้เมาส์ (AC-35)
- **toast เลิกทำ:** `role="status"` อ่านตอนปรากฏ · เป็นปุ่มที่ Tab ถึงได้ (เป็นจุด Tab ถัดจากตาราง) · หยุดนับ 5 วินาทีขณะ focus/ชี้ · พ้นเวลาแล้วลบเท่านั้น (เลิกทำย้อนหลังไม่ได้ — ต้องกรอกใหม่)
- **ประกาศ (aria-live polite):** ผลบันทึก · ผิดตรวจ (`role="alert"` เฉพาะ error ที่บล็อกการบันทึก) · "ตอนนี้" เปลี่ยน (หน้าหลัก) · ออฟไลน์/ออนไลน์เปลี่ยน
- **label ทุกช่อง:** ชนิด (fieldset+legend "ชนิดคาบ") · ห้อง วิชา ชื่อกิจกรรม มี `<label>` ที่มองเห็น · เวลาแต่ละช่อง label ซ่อน "เวลาเริ่มคาบ 2" "เวลาจบคาบ 2" "ชื่อช่วงพักที่ 1" · วันเรียนเป็น fieldset+legend "วันเรียน" ปุ่ม `aria-pressed`
- **พื้นที่กด ≥ 44px (จอสัมผัส):** ช่องตาราง iPad ≥ 44×44 (ความสูงช่อง ก/ข ≥ 56px) · "+" ในช่องว่างเป็นพื้นที่กดของทั้งช่อง · ปุ่ม − + จำนวนคาบ · ชิปวัน · ปุ่มเช็คชื่อบนแถบ ≥ 44px · ระยะห่างปุ่ม ≥ 8px
- **ไม่พึ่งสีอย่างเดียว:** สอนห้อง = ไอคอนห้อง (ประตู/กระดาน) · กิจกรรม = ไอคอนดาว + ป้ายคำ "กิจกรรม" · ตอนนี้/ต่อไป/วันนี้/เก็บแล้ว/ใหม่ = ป้ายคำ · วันเรียนที่เลือก = ✓ · พักกลางวัน = ลายทแยง + ข้อความ · เส้นตอนนี้ = เส้นทึบ + ป้ายคำ · error = ไอคอน ! + ข้อความ
- **contrast:** ข้อความ ≥ 4.5:1 ป้าย/ไอคอน/เส้นกรอบช่อง ≥ 3:1 ทั้ง 3 ธีม × สว่าง/มืด (6 ชุด) · "จาง" ของห้องเก็บแล้วต้องยังผ่าน 4.5:1 (ลดน้ำหนัก/เส้นประแทนลด opacity)
- **ตัวอักษรขนาดใหญ่/ซูม:** รองรับ 24px (ตั้งค่าแอป) · ใช้หน่วย rem · ไม่ตัดแนวตั้ง · ตามกติกาสลับเป็นรายการวัน
- **ไม่มี motion ใหม่:** ไม่มี transition เลื่อน/สไลด์ของแผ่น (ปรากฏทันที) · เส้น "ตอนนี้" ไม่เคลื่อนต่อเนื่อง กระโดดทุก 60 วินาที · เคารพ `prefers-reduced-motion` เสมอ · ไม่เลื่อนอัตโนมัติหลังเปิดครั้งแรก

## จุดที่ draft.html ต้องแก้ใน mockup เต็ม (ตรวจจากไฟล์: ฟอนต์ 12–11px หลายจุด · ช่องว่าง ก `opacity:0` ตอนไม่ชี้)

3. **ข บนคอม 729px ต้องเลื่อนดูบ่าย** → บีบพักกลางวัน ~28px และคาบ ~64px ให้ 7 คาบ + พัก พอดี (≈516px) ไม่เลื่อน
4. **ค บนจอใหญ่ ไม่เห็นทั้งสัปดาห์ / กรอกครั้งแรกกดหลายครั้ง** → จอ ≥ 1180 แบ่ง 2 คอลัมน์ มีตารางย่อทั้งสัปดาห์กดแก้ได้ + แผ่นจำห้อง/วิชาล่าสุดให้ Enter-Enter

6. ต้องเพิ่ม: ตัวเลือกรูปแบบ + ลิงก์ "ตั้งแถบตารางสอนในหน้าหลัก ›" ใน ตั้งค่า › หน้าตา · การ์ดตารางสอนเปิด/ปิดแยกต่อโครงใน ปรับหน้าหลัก · แผ่นตั้งเวลาคาบ · กล่องยืนยัน 3 ชนิด · สถานะออฟไลน์/409/ปีเก่า/ว่าง/โหลด · หน้าพิมพ์ A4 · แสดงทั้ง 3 รูปแบบครบ 4 อุปกรณ์ · วัดว่าหน้าหลักพอดี 1536×729 หลังเพิ่มแถบ+คาบแทรก
