## User flow

### Flow 1: กรอกตารางครั้งแรก (คอม/iPad) — เป้าหมาย ≤ 4 นาที

1. เมนู › "ตารางสอน" → เห็นตารางว่าง + กล่อง "ยังไม่มีตารางสอนภาคนี้" มีปุ่มหลัก "ตั้งเวลาคาบ" (ถ้ายังไม่เคยตั้ง) และ "คัดลอกจากภาคก่อน" (ถ้ามี) · ช่องว่างทุกช่องมีเครื่องหมาย "+" มองเห็นตลอด ไม่ต้องชี้
2. กด "ตั้งเวลาคาบ" → แผ่น S5 มีค่าเริ่มตรงรูป (7 คาบ พักกลางวัน จ–ศ) → ถ้าตรงกับโรงเรียนแล้วกด "บันทึก" ได้เลย
3. แตะ "+" ที่ จันทร์ คาบ 2 → แผ่น S4 ชนิด "สอนห้อง" ถูกเลือกไว้ · เลือกห้อง ป.6/2 · วิชา คณิตศาสตร์ → Enter/บันทึก → ช่องแสดง "คณิตศาสตร์ ป.6/2" ทันที · แผ่นปิด โฟกัสกลับช่องนั้น
4. ทำซ้ำช่องถัดไป (ลูกศรเลื่อนช่อง Enter เปิดแผ่น) · แผ่นจำห้อง/วิชาล่าสุดเป็นค่าเลือกเริ่มต้นของช่องถัดไป (กด Enter บันทึกได้เร็ว) — คำแนะนำ ไม่ใช่ AC
5. คาบกิจกรรม: เลือก "กิจกรรม" → พิมพ์หรือแตะชิป "PLC / ลูกเสือ / ชุมนุม / สวดมนต์" (ชื่อที่เคยใช้ในภาคนี้/ก่อนหน้า) → บันทึก
6. เห็นสรุปล่าง "สอน 9 · กิจกรรม 5 · รวม 14 คาบ (14 ชม.)"

### Flow 2: ดูระหว่างวันบนมือถือ

1. เปิดแอป → หน้าหลักมีแถบ "ตอนนี้ · คาบ 2 · ถึง 10:30 · คณิตศาสตร์ ป.6/4 [เช็คชื่อ ป.6/4]" → แตะปุ่ม → หน้าเช็คชื่อ ป.6/4 วันนี้ (ไม่แก้ข้อมูล)
2. หรือเมนู "เพิ่มเติม" › "ตารางสอน" → เปิดที่วันนี้ (ไม่ใช่วันเรียน = วันเรียนถัดไป) · รายการคาบเรียงเวลา ป้ายคำ "ตอนนี้" "ต่อไป" · ชิปวัน จ–ศ

### Flow 3: แก้/ลบคาบ

แตะช่องมีข้อมูล → เมนูเล็ก (เช็คชื่อ · สแกน · แก้คาบนี้) → "แก้คาบนี้" → S4 โหมดแก้ → "ลบคาบนี้" ที่ท้ายแผ่น (ปุ่มแดงข้อความชัด) → ช่องว่างทันที + toast "ลบคาบ คณิตศาสตร์ ป.6/2 (อังคาร คาบ 6) แล้ว [เลิกทำ]" 5 วินาที (หยุดนับถอยหลังขณะโฟกัส/ชี้ที่ toast · แป้น Ctrl/⌘+Z = เลิกทำ)

### Flow 4: ขึ้นภาคใหม่

ภาคใหม่ตารางว่าง → ปุ่ม "คัดลอกจากภาค 1/2569 (14 คาบ)" → (ปลายทางว่าง: คัดลอกเลย · มีคาบ: S9-ค ถามแทนที่) → ผลสำเร็จ "คัดลอก 14 คาบแล้ว" · ข้ามปี: "คัดลอก 11 คาบ · ไม่ได้คัดลอก 3 คาบ: ป.6/4 ไม่มีในปี 2570" + รายการ (จันทร์ คาบ 5 · พุธ คาบ 2 · ศุกร์ คาบ 3) ค้างอยู่ในแถบจนครูปิดเอง

### Flow 5: ลดคาบ/เอาวันออก

S5 แก้เป็น 6 คาบ → "บันทึก" → S9-ข "จะลบ 2 คาบในคาบ 7: PLC กลุ่มสาระ (จันทร์), PLC สายชั้น (ศุกร์) — ลบจากทุกภาคของปีนี้" [ยกเลิก] [ลบและบันทึก] · ไม่มีคาบหลุด → บันทึกเลยไม่ถาม

### Flow 6: พิมพ์

ปุ่ม "พิมพ์" ในหัวหน้า (ทุกรูปแบบ) → เปิดกล่องพิมพ์ของเครื่อง ด้วยหน้า S8 (ไม่ขึ้นกับรูปแบบที่เลือก) — ดูหัวข้อพิมพ์ด้านล่าง

## แผ่นกรอก/แก้คาบ (S4) — ละเอียด

โครง: หัวแผ่นแสดงตำแหน่งอ่านอย่างเดียว "วันพุธ · คาบ 4 · 12:30–13:30" (ไม่ให้เปลี่ยนวัน/คาบในแผ่น = ไม่มีกรณีย้ายไปชนช่องอื่น) · แสดงเป็น "dialog กลางจอ กว้าง 440px" บนคอม/iPad และ "bottom sheet สูงสุด 90% ของจอ มีปุ่มบันทึกติดล่าง" บนมือถือ · `role="dialog" aria-modal="true"` · focus trap · Esc/ปุ่ม "ยกเลิก" ปิดแล้วโฟกัสกลับช่องเดิม

```
┌ เพิ่มคาบ · วันพุธ · คาบ 3 · 10:30–11:30 ──────── [✕] ┐
│ ชนิด    (●) สอนห้อง   ( ) กิจกรรม      ← radio 2 ปุ่ม │
│ ห้อง *  [ ป.6/1            ▾ ]                        │
│ วิชา    [ คณิตศาสตร์       ▾ ]   (ไม่ระบุก็ได้)       │
│                       ─── หรือชนิดกิจกรรม ───          │
│ ชื่อกิจกรรม *  [ PLC__________ ] 3/40                 │
│ ที่เคยใช้: [PLC] [ลูกเสือ] [ชุมนุม] [สวดมนต์]         │
│ [ลบคาบนี้]  (เฉพาะโหมดแก้)        [ยกเลิก] [บันทึก]   │
└───────────────────────────────────────────────────────┘
```

| ยังไม่มีห้องในปีนี้ (AC-10ข) | ชนิดสอนห้องแสดง "ยังไม่มีห้องในปีนี้" + ลิงก์ "เพิ่มห้องในตั้งค่า" · ชนิดกิจกรรมใช้ได้ |
| "ชนคาบเดิม" | ช่องหนึ่งมีได้ 1 รายการ จึงออกแบบให้ชนไม่ได้จากหน้าจอ (แผ่นล็อกตำแหน่ง · ช่องมีข้อมูล = โหมดแก้ ไม่ใช่เพิ่มซ้อน) · ชนจริงเกิดได้ทางเดียว: อีกเครื่องกรอกช่องนี้ก่อน → 409 → ดูแถว "ชนกันสองเครื่อง" ในตารางสถานะ · ไม่ต้องมีกล่อง "แทนที่?" ในแผ่น |
| ออฟไลน์ | เปิดแผ่นไม่ได้ (ช่องไม่ใช่ปุ่มแก้) ดูแถวออฟไลน์ |

| กำลังบันทึก | ปุ่ม "บันทึก" → "กำลังบันทึก…" ปิดกดซ้ำ ฟอร์มยังเห็น · ล้ม → แผ่นเปิดค้าง ข้อมูลที่พิมพ์ไม่หาย + ข้อความ "บันทึกตารางสอนไม่สำเร็จ" [ลองอีกครั้ง] |

ปุ่ม: "บันทึก" (Enter ในช่องข้อความ) · "ยกเลิก" (Esc) · "ลบคาบนี้" · จุดกด ≥ 44px · ใช้ select ของระบบ (VoiceOver/iPad ใช้ได้ดี ไม่เขียน dropdown เอง)

## รูปแบบทั้ง 3 — โครงต่างกัน

### ก ตารางสัปดาห์แบบกระดาษ

แถว = วัน (จ–ศ + วันเสาร์/อาทิตย์ถ้าเปิด) · คอลัมน์ = คาบ 1–n โดยพักเป็น "คอลัมน์แคบแนวตั้ง" คั่น เขียน "พักกลางวัน 11:30–12:30" หมุน 90° ทุกวันต่อเนื่องเป็นแถบเดียวตลอดแถว · หัวคอลัมน์ "คาบ 4 / 12:30–13:30" · ช่องว่าง = กรอบเส้นประ + "+" มองเห็นตลอด · วันนี้: ชื่อวันมีป้าย "วันนี้" (คำ) + เส้นขอบหนา · ช่วงเวลา "ตอนนี้": หัวคอลัมน์ + ช่องในแถววันนี้มีป้าย "ตอนนี้" (เฉพาะวันนี้) · ช่องแสดง: บรรทัด 1 ชื่อห้อง (ไอคอนห้อง) บรรทัด 2 วิชา · กิจกรรม: ไอคอนดาว + ชื่อ + ป้ายคำเล็ก "กิจกรรม" · ใช้ ≥ 13px ทุกข้อความ

### ข ปฏิทินแกนเวลา (สไตล์ Google Calendar)

แกนเวลาแนวตั้ง 08:30→16:30 · คอลัมน์ = วัน · บล็อกคาบสูงเท่าความยาวคาบ · ช่วงพักเป็นแถบแคบลายทแยงเต็มความกว้าง (พักกลางวันบีบสูง ~28px ไม่ตามเวลาจริง เพื่อให้ 7 คาบ + พัก พอดีที่ความสูงคอม 729: ช่องคาบ 64px × 7 + พัก 28 + หัว 40 ≈ 516px) · เส้น "ตอนนี้" = เส้นทึบ + ป้ายคำ "ตอนนี้ 09:45" ที่ปลายซ้าย (ไม่ใช่สีแดงอย่างเดียว) · สวิตช์ "วัน | สัปดาห์" (radio กลุ่ม) · ปุ่มลอย/ปุ่มหัว "+ เพิ่มคาบ" (เปิด S4 พร้อมถามวัน/คาบ → เพราะแผ่นล็อกตำแหน่ง ปุ่มนี้เปิดตัวเลือกช่องว่างที่ยังไม่มีคาบ เป็นรายการ "วัน/คาบ" ให้เลือกก่อน 1 ขั้น) · ช่องว่างแสดงเส้นประ + "+" มองเห็นตลอด (draft ซ่อนจนชี้ — ต้องแก้) · มุมมองวัน: คอลัมน์เดียวกว้างเต็ม เปิดที่วันนี้ · ถ้าเนื้อหาสูงกว่าจอ เลื่อนภายในกรอบตาราง หัววันติดบน และเปิดเลื่อนมาที่ "ตอนนี้" แต่ไม่เลื่อนอัตโนมัติซ้ำ

### ค วันนี้เป็นหลัก

บนสุดการ์ด "ตอนนี้ · คาบ 2 · ถึง 10:30 · คณิตศาสตร์ ป.6/4 [เช็คชื่อ ป.6/4] [สแกนงาน]" และ "ต่อไป · คาบ 4 · 12:30 · …" · ใต้ลงมา "วันนี้ (พุธ 11 พ.ย.)" รายการคาบเรียงเวลา (คาบผ่านแล้วจาง + คำ "เสร็จแล้ว") ครบทุกคาบรวมคาบว่างเป็นแถว "คาบ 3 · 10:30–11:30 · ว่าง [+ เพิ่ม]" · พักเป็นแถวแบ่ง · ถัดลงไป "ทั้งสัปดาห์" ตัวแก้: ชิปวัน จ–ศ เลือกแล้วแสดงรายการคาบของวันนั้น (ทุกคาบเป็นแถวเดียวกัน แตะแถว = เมนู/แผ่น) · บนจอใหญ่ (≥ 1180) แบ่ง 2 คอลัมน์: ซ้ายการ์ด+วันนี้ ขวาแผงทั้งสัปดาห์ (ตารางย่อ กด ช่อง/วัน เพื่อไปแก้) · ท้ายหน้า สรุป

## ตั้งค่า › หน้าตา (S7) — ส่วนเพิ่ม

| หัวกระดาษ | "ตารางสอน ภาคเรียนที่ 2 ปีการศึกษา 2569" · บรรทัดชื่อ (N2 · BR-16 · AC-65): จาก "ชื่อครู" "ชื่อโรงเรียน" ในตั้งค่า เฉพาะที่กรอกไว้ — ทั้งคู่ "ครูผู้สอน ครูทดสอบ · โรงเรียนบ้านตัวอย่าง" · ครูอย่างเดียว "ครูผู้สอน ครูทดสอบ" · โรงเรียนอย่างเดียว "โรงเรียนบ้านตัวอย่าง" · ว่างทั้งคู่ = ไม่มีบรรทัด (ไม่มีป้ายเปล่า "ครูผู้สอน:" หรือเส้นให้เขียน) · วันที่พิมพ์ · ไม่มีช่องลงชื่อผู้บริหาร ไม่มีชื่อนักเรียน |
