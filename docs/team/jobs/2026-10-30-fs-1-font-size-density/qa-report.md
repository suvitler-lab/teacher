## สรุปผู้บริหาร
วัดบนโค้ดสุดท้าย (dist build 18:01) ด้วย browser จริง ข้อมูลสมมติ: ข้อความเล็กกว่า 13px = 0 ทุกหน้า/ทุกขนาด/ทุกความหนาแน่น, ไม่มีหน้าไหนเลื่อนแนวนอน, ค่าเสียใน localStorage ไม่ทำแอปพัง (ใช้ค่าเริ่มต้น 18), ปุ่ม +/− มี aria-label และสูง 56px.
