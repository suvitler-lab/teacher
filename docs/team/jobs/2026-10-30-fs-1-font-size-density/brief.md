## โจทย์

> เจ้าของงาน: "สิ่งที่คุณควรทำคือตั้งค่าให้มันเพิ่มขยายตัวอักษรได้ แบบรูปที่ส่งไป" · "อันนี้หน้าสแกนเดิม มันเล็กไปนิด" · ผลเดินดูระบบจริง: ตัวอักษรส่วนใหญ่ 11–13px ทั้งระบบ, ปุ่มเล็กกว่า 44px พบทุกหน้า

ออกแบบแล้ว (อนุมัติ D30): `jobs/2026-10-30-m2-00-scan-mockups/ux.md §3` + `design/settings.html` + `design/pages.html`

## ขอบเขต

1. โมดูลตั้งค่าการแสดงผลต่อเครื่อง (`localStorage` เหมือน theme · ไม่แตะ server/DB/migration): ขนาดตัวอักษร 14–24 ครั้งละ 1 (เริ่มต้น 18 บนจอสัมผัส iPad/มือถือ, 16 บนคอม) + ความหนาแน่น กระชับ/ปกติ/โปร่ง · ใช้ก่อนวาดหน้าแรก (ไม่กะพริบขนาด)
2. CSS ทั้งแอป: เลิก `font-size` และขนาดปุ่ม/แถวแบบ px ตายตัว → ใช้ rem / ตัวแปร (`--fs`, type scale ตาม ux.md §3) · ข้อความไม่เล็กกว่า 13px ที่ทุกระดับ · ปุ่ม/ช่องกด ≥ 44px บนจอสัมผัส · ไม่แตะ `print.css` (หน่วยพิมพ์แยก)
3. TSX ที่ตั้ง `fontSize` แบบ px ตรง ๆ (inline) → ใช้ตัวแปร/คลาส
4. ตั้งค่า → ทั่วไป: แถวขนาดตัวอักษร (− [ค่า] + ค่าเริ่มต้น ปุ่ม ≥ 56px) + แถวความหนาแน่น + การ์ด "ตัวอย่างสด" ตาม `settings.html`
5. ไม่มีหน้าไหนเลื่อนแนวนอนทั้งหน้าที่ 390 / 820 / 1180 / 1440 กว้าง ที่ขนาด 14 / 18 / 24 (ตารางกว้างเลื่อนในกรอบของตัวเอง)

นอกขอบเขต: เปลี่ยนหน้าสแกน (scan-1), สมุดคะแนน 10–15 คอลัมน์ (gb-1), โหมดฉายจอ, สี/ไอคอน (vp-*), ป้ายไทยใน AuditHistory (เก็บไว้ทำพร้อมงานนี้ได้ถ้าไม่ขยายขอบเขต — ไม่บังคับ)
