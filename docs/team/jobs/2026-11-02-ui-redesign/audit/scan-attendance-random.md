## สรุป 5 บรรทัด

1. ฟีเจอร์แกนของ 3 หน้าอยู่ครบ: การ์ดปรับได้ซิงก์ผ่านตั้งค่า, วันที่รับงานย้อนหลัง (C-03 AC-06/07/08), เหตุผลส่งไม่สำเร็จเป็นไทย, ปุ่มสถานะ 5 ปุ่ม, มาทั้งห้องไม่ทับคนที่เช็คแล้ว, การ์ดสุ่มชื่อ 7 ใบ, โหมดฉายจอ 3 หน้ากดค้างออก/Esc — แต่ "ขัดเกลา" ตามสเปกหายไปเยอะ โดยเฉพาะ action sheet, เมนูเปลี่ยนโหมดกลางรอบ, ปุ่มทดสอบเครื่องยิง, จำนวนคนในกล่องปิดรับงาน.
2. **ช่องเช็คชื่อคลิกไม่ได้** (ผู้ใช้รายงาน): ไม่พบ overlay ที่บังถาวร สาเหตุในโค้ดที่เป็นไปได้สูงสุดคือ (ก) แตะช่องที่สถานะเท่ากับปุ่มที่เลือกอยู่ → ไม่มีอะไรเปลี่ยน/ไม่มีฟีดแบ็ก และยกเลิกกลับเป็น "ยังไม่เช็ค" ไม่ได้ (`Attendance.tsx:189-192`) (ข) ทั้งตารางถูกล็อก `pointer-events:none` + `if(!loaded) return` ระหว่างโหลด/เปลี่ยนห้อง-วัน-คาบ นานสูงสุด ~8 วิถ้าเน็ตช้า โดยไม่มีข้อความ (`attend.css:27`, `Attendance.tsx:190`) (ค) ปุ่มลอย "ส่งไม่สำเร็จ n" ทับมุมขวาล่าง + แถบบันทึก z-index 35 บังแถวล่างสุด (ง) race ของ `draftGet().then(setDraft)` ทับสถานะที่เพิ่งแตะ — รายละเอียดข้อ B-1.
3. พบข้อบกพร่องพฤติกรรมอื่น: โหมดฉายจอบังคับ method=สแกนแล้วไม่คืน (ช่องแตะใช้ปุ่มสถานะที่ซ่อนอยู่), "ทิ้ง" รายการต้องตรวจสอบโดยไม่ยืนยัน, ข้อความ "กลุ่มละ ~n คน" ผิดในโหมด "กี่กลุ่ม", ช่วงเลขที่เริ่มที่ 99 ต้องกดลดทีละ 1, ปุ่ม "ไปเช็คชื่อ" ไม่ส่งห้อง, ลำดับการ์ดที่ปรับในลิ้นชักไม่มีผลกับ 3 หน้า (`order` ไม่ถูกใช้เลย).
4. a11y/ฉายจอ: หน้าสแกนระหว่างรอบไม่มี `h1`, ช่องผังไม่มี aria-label/ไอคอน (พึ่งสี), เวทีสุ่มประกาศทุกเฟรมที่หมุน, ฉายจอไม่ย้ายโฟกัส/ไม่ `inert` หน้าหลังที่ยังอยู่ใน DOM (มีคะแนน/คำขาดป่วยลา), ธีมสว่างยังใช้ `--pj-ok:#0d6a3a` (6.69 < 7 ที่สเปกสั่งแก้เป็น `#0a5a31`).
5. นับจาก 93 ข้อ: ✅ 27 · ⚠️ 43 · ❌ 21 · ➖ 2 (บรรทัด "ผลรวม" ท้ายตาราง) · ขนาดแตะ ≥44 / ฟอนต์ ≥13 ผ่านด้วยกฎกลาง (`scan.css:115-117`, `base.css:169-176`, `tokens.css:64-65`) แต่ยังไม่ได้ตรวจด้วยตา/เบราว์เซอร์ตามที่ brief ระบุไว้ใน "งานเก็บ".

> หมายเหตุขอบเขต: ไม่ได้เปิดเบราว์เซอร์ตามคำสั่ง จึง **ทำซ้ำอาการช่องคลิกไม่ได้ไม่ได้จริง** — สาเหตุเรียงตามความน่าจะเป็นจากโค้ด (ระบุระดับความมั่นใจไว้) ขั้นตอนทำซ้ำอยู่ท้ายไฟล์.

### ระดับ 1 — บั๊กที่ผู้ใช้เจอ / ข้อมูลเสี่ยง

**B-1 (A8) ช่องเช็คชื่อบางช่องคลิกไม่ได้ — `src/pages/Attendance.tsx`, `src/styles/attend.css`** (ไม่ได้ทำซ้ำจริง: อ่านโค้ดอย่างเดียว)
ไม่พบ overlay/`z-index` ที่บังช่องถาวร (ตรวจแล้ว: `.att-savebar` sticky z35, `.bottom-tabs` z50, `.failed-fab` z140, `.toast-stack` z300 เฉพาะ 4 วิ, ลิ้นชัก/เมนูโผล่เมื่อเปิด) สาเหตุที่เข้ากับอาการ "บางช่อง" เรียงตามความน่าจะเป็น:
1. **(มั่นใจสูง — พฤติกรรมที่ผู้ใช้มองเป็น "คลิกไม่ได้")** แตะช่องที่สถานะ = ปุ่มสถานะที่เลือกอยู่ (ค่าเริ่ม "มา", และหลังกด "มาทั้งห้อง" ทุกช่องเป็น "มา") → `tap()` (:189-192) เรียก `applyEdits` สร้างแถวร่างใหม่สถานะเดิม หน้าจอไม่เปลี่ยนเลย ไม่มีไฮไลต์/เสียง/ข้อความ และไม่มีทางเปลี่ยนกลับเป็น "ยังไม่เช็ค" (เซิร์ฟเวอร์ไม่มี API ยกเลิก — ดูคอมเมนต์ :199). ผลคือเห็นเป็นช่องที่ "ตาย" เฉพาะบางช่อง.
