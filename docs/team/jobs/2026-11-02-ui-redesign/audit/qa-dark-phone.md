## 1536x864 (เดสก์ท็อป) — ผลเบื้องต้น
- ข้อความ: ไม่มีข้อความตัวจริงที่ต่ำกว่า 4.5:1 ทั้ง 8 หน้า, เมนู ⋮ (นักเรียน/งาน), ลิ้นชัก "ปรับการ์ด", ลิ้นชักนักเรียน, popover โหมดฉายจอ, modal แก้คะแนน
- ข้อยกเว้นที่เป็น disabled (opacity .5) ไม่นับ: ปุ่ม "สุ่มเลย", "บันทึก", "ค่าเริ่มต้น", วันที่ "ยังไม่ถึง"
- B-D1 (ต่ำ) badge จำนวนนักเรียนบน pill ห้อง `span.n` ตัวเลข "4","3": สี #a7afbd opacity .75 บน #232833 = 4.43:1 (ต่ำกว่า 4.5 นิดเดียว) — ทุกหน้าที่มีแถบห้อง; เดาไฟล์: src/styles/base.css (.pill .n opacity .75)
- B-D2 (กลาง/ต่ำ, ระบบ) ขอบปุ่ม/ช่องกรอกในโหมดมืด --border (#fff 10%) / --border-strong (18%) ต่อพื้นการ์ด ≈ 1.3–1.8:1 (< 3:1 ตาม WCAG 1.4.11) ปุ่ม `.pill`, `.submit`, `.ghost`, `select`, `input.text` (ช่องค้นหานักเรียน/ตั้งค่า), `.att-tile`, `.stbtn`; ไม่ใช่ปัญหาการอ่านเพราะมีข้อความ แต่ขอบเขตปุ่มจางมาก; แก้: ใช้ --border-strong ≥ rgba(255,255,255,.34) สำหรับ control; ไฟล์: src/styles/tokens.css `:root[data-theme="dark"]` + base.css
- B-D3 (ต่ำ) สวิตช์ "ปิด" ใน ลิ้นชักปรับการ์ด: track rgba(255,255,255,.18) vs พื้นลิ้นชัก = 1.79:1 และ knob สีเข้ม แยกสถานะปิด/เปิดอาศัยสีฟ้าอย่างเดียว; ไฟล์: .switch ใน base.css
- focus ring: `:focus-visible {outline:2px solid var(--accent)}` = #5a92ee บน #14171d ≈ 6:1 ผ่าน (grade.css .gb-mini ใช้เหมือนกัน)
