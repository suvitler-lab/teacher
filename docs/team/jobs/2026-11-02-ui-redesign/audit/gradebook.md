## สาเหตุการ์ดใต้ตารางตัวอักษรซ้อนกัน (ที่ผู้ใช้เจอ)

### 1) การ์ด "รอตรวจ" / "ควรปิดรับ" — ชื่องานทับบรรทัดถัดไป

- โค้ด: `GradebookCards.tsx:75` และ `:83` ทำแต่ละแถวเป็น `<button class="gc-row"><span class="grow">{a.title}</span><Chip/></button>`
- ต้นเหตุ: `src/styles/base.css:34` สั่ง **ทุก** `button { height: 2.53rem; display:inline-flex; align-items:center }` (ความสูงตายตัว ≈ 40px ที่ฟอนต์ 16) เดิม `.gc-row` ตั้งแค่ `min-height: var(--tap)` ไม่ได้รีเซ็ต `height` → ชื่องานยาวที่ตัดบรรทัดเป็น 2 บรรทัด (line-height 1.6 → ~51px) สูงกว่ากล่อง 40/44px; เพราะ `align-items:center` ข้อความล้นออกทั้งบนและล่างของปุ่ม แล้วไปทับแถวก่อน/หลัง (ปุ่มไม่ขยายตามเนื้อหา) ยิ่งฟอนต์ 18/24 ยิ่งเกิดบ่อย
- ตัวทำให้แย่ลง: `@media (max-width:720px) .hm-chip { white-space: normal }` (home.css:20) ทำให้ชิป "เลยกำหนด" ตัดบรรทัดบนมือถือด้วย · `.gc-row` ไม่มี padding แนวตั้งและ line-height ของแถวยังเป็น 1.6 จาก body
- เปรียบเทียบ: `.hm-follow` (home.css:106) เขียน `height:auto; min-height:var(--row-h)` ไว้ จึงไม่ซ้อน — `.gc-row` ลอกแบบมาไม่ครบ
- **สถานะ ณ ตอนตรวจ:** ไฟล์ `grade.css` ถูกแก้เมื่อ 23:36 (ตอนที่ผมกำลังอ่าน) เพิ่มบรรทัด 200-205:
  `.gc-row { …; height: auto; min-height: var(--tap, 44px); padding: 6px 0; line-height: 1.4; }` + `.gc-row > .grow { min-width:0; overflow-wrap:anywhere }` + `.gc-row > .chip, .gc-row > .hm-chip { flex:none }` — **การแก้นี้ถูกต้องและพอ** (เหลือแค่ต้องยืนยันด้วยตาที่ iPad 18/24 และมือถือ) · ถ้าใครยังเห็นซ้อน = เบราว์เซอร์ยังถือ CSS เก่า (Vite HMR/service worker แคช) ให้รีโหลดแบบ hard refresh
- วิธีแก้ที่แนะนำเพิ่ม (กันซ้ำกับปุ่มอื่น): ใน base.css เปลี่ยนกฎกลางเป็น `min-height: 2.53rem` แทน `height` ไม่ได้ (กระทบทั้งแอป) → ให้ใช้คลาสกลาง `button.row-btn { height:auto; min-height: var(--tap); white-space: normal; text-align:left; line-height:1.4 }` แล้วให้ `.gc-row`, `.hm-follow`, `.hm-att-link` ใช้ร่วมกัน; และเพิ่มเทสต์ภาพ (สร้างชื่องาน 60 ตัวอักษรไทย) ที่ 18/24

### 2) การ์ด "คำอธิบาย" แน่น

- โค้ด: `GradebookCards.tsx:87-103` + `grade.css:100` `.gb-legend { display:flex; gap:12px; flex-wrap:wrap; font-size:var(--fs-xs) }`
- ต้นเหตุ (จากโค้ด; ผมไม่ได้เปิดดูภาพ): (ก) 9 รายการเป็น `<span>` ที่เป็น flex item แบบหดได้ → ที่การ์ดกว้าง 260–300px ข้อความข้างสวอตช์ตัดบรรทัดกลางรายการ ("ยังไม่ถึงกำหนด", "รอส่งขึ้นระบบ") แล้วบรรทัดสองไปอยู่ใต้สวอตช์ ไม่เป็นคอลัมน์ (ข) `.wcell` สูง 1.6rem (ui.css:63) แต่ line-height ของ legend = 1.6×0.85rem ≈ 1.36rem → แถวสูงไม่เท่ากัน (ค) ช่อง "ยกเว้น" ใน WorkCell กว้างตามคำ ("ยกเว้น" ui.tsx:208) แล้วข้อความข้างๆ เขียน "ไม่นับ" ต่อกันเป็น "ยกเว้น ไม่นับ" (ง) ข้อความวิธีใช้ยาวบรรทัดเดียว ~190 ตัวอักษร `.page-sub` margin-top 6px ติดกับสวอตช์ ไม่มีเส้นแบ่ง

  4. `GradebookCards.tsx:96` เปลี่ยน "ไม่นับ" เป็น "ยกเว้น" (สเปก ux §4) และตัดสวอตช์ซ้ำคำ (สวอตช์เขียนคำว่า "ยกเว้น" อยู่แล้ว ให้ข้อความข้างเป็น "ไม่นับในอัตราส่ง")
