# หัวคอลัมน์สมุดคะแนน — 3 ทางเลือก (ดูที่ preview.html)

ปัญหาเดิม: แถบสีบนหัวงานบาง 4px สีเดียวกับเส้นขอบ ชนิดงานแยกแค่ด้วยสี (พึ่งสีอย่างเดียว) และข้อมูลรอง (เต็ม/ส่ง/ตา/แถบ %) อัดกันเป็นก้อนเดียว
ทุกทางเลือก: รูปทรงประจำชนิด (วงกลม สี่เหลี่ยม สามเหลี่ยม เพชร ดาว) หน้าชื่อ -> ไม่พึ่งสีอย่างเดียว · วันส่งใช้ไอคอนปฏิทิน (ตัดคำ "ส่ง") ให้พอดี 7.6rem
ปิดรับ = ไอคอนกุญแจ, ซ่อนคะแนน = ตาขีด (มุมขวาบน ซ้อนเรียงแนวตั้ง) · ⋮ แสดงเฉพาะคอลัมน์ที่เลือก (ขยาย hit 44px บน touch) · ชื่อ clamp 2 บรรทัด + title

เดิมประมาณ 78px (ไม่ได้วัดในแอปจริง คำนวณจาก CSS). แถวหัวรวมกลุ่มบนคอม: A/C ≈ 71+32 = 103px ถ้าลด --gb-gh เหลือ 2rem; B ≈ 126px.
ที่ 1536x729 ใช้พื้นที่ตารางราวครึ่งจอ A/C ยังคงได้ 8 แถวข้อมูล (36-38px/แถว) ส่วน B เสี่ยงเหลือ 7

## คำแนะนำ: ทาง C ผสมแถบกลุ่มสีย้อมของ A
เหตุผล: เตี้ยสุด (คอมต้องเหลือ 8 แถว) ชนิดมีรูปทรง+สี+เส้น, แถบกลุ่มใช้ tint-bg ให้โหมดจัดกลุ่มเห็นชนิดชัด
ถ้าเจ้าของงานอยากให้ "สีเด่น" มากกว่านี้ ให้เลือก A (สูงเท่ากัน)

## สิ่งที่ต้องแก้ใน grade.css (+ โครง th ใน Gradebook.tsx ต้องเพิ่มรูปทรงชนิด, .hd-corner, ไอคอนปฏิทิน)
- `table.gb thead th.col-w` : เปลี่ยน `border-top:4px solid var(--border)` เป็น 3px (สีมาจาก inline เดิม) และ padding `.25rem .3rem 0`
- `.ht` ลด `min-height:2.6em` ให้ยังคง 2 บรรทัด แต่เพิ่มคลาส `.ht-shape` (รูปทรง 12px ใช้ currentColor = fg)
- `.hs` : เปลี่ยนข้อความเป็น `เต็ม N` + `.hs-cal` (ไอคอน 12px) + วัน ไม่ใส่คำ "ส่ง" (ยังอยู่ใน title)
- `.hs-eye` และกุญแจ(ใหม่ `.hs-lock`) ย้ายไปกล่อง `.hd-corner` (absolute, top/right 2px, คอลัมน์แนวตั้ง กว้าง 24px) ใส่ `padding-right:22px` ให้ `.ht` เมื่อมีไอคอน
- `.hbar` : เปลี่ยนจากแถบ 6px ในเซลล์เป็นเส้น 3px ชิดขอบล่าง (`margin:0 -.3rem`)
- ตัวแปรใหม่ `--gb-gh: 2.4rem` เป็น `2rem` บน `(hover:hover) and (pointer:fine)` (touch คงเดิม max(var(--tap),2.4rem))
- `.gh-cell` : พื้น `var(--tint-X-bg)` คงเดิม, เพิ่ม `.gh-shape` หน้า `.gh-label` (รูปทรงชนิด) และลดตัวอักษรนับเป็น `.gh-cnt` (weight 500)
- `.sumcol` (หัวกลุ่มที่พับ) ใช้ `.ht-shape` เหมือนกัน
