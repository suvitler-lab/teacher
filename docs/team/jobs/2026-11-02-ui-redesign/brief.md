#### คำถาม Gate 3 (หน้าคะแนน)

2. "ปิดรับงาน" ปุ่มตรงในแผงงาน + ยืนยัน (แนะนำ) หรือคงใน ⋮
3. iPad ตั้ง: ตารางแคบ ชื่อ + 5 งาน + สะสม (แนะนำ) / ซ่อนสะสม / ทีละงาน (สลับได้ในตัวกรอง)
4. ไอคอนตาหลังตัดสวิตช์ผู้ปกครอง: "ซ่อนคะแนนบนจอ" · ประเภทสอบเริ่มต้นแสดง (แผน) หรือซ่อนแต่บอกในฟอร์ม (UX/SA)
