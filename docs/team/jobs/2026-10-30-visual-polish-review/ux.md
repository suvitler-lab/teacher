## วิธีตรวจ / หลักฐาน

- ตารางไอคอน: `grep` ทุก `<Icon name=...>` และชื่อที่ส่งผ่าน prop (`icon:`/`icon=`) ใน `src/` → 79 ชื่อ + ชื่อแบบ dynamic (`eye/eye-off`, `lock-open`, `bulb/bulb-off`, ไอคอนของประเภทงานจาก DB)
- ชื่อไอคอนที่เสนอทุกตัวตรวจแล้วว่ามีใน `node_modules/@tabler/icons-webfont/dist/tabler-icons.css` (v3.48) — ไม่มีตัวที่หาย
- หน้าจอจริง: fixture server (ข้อมูลสมมติ, พอร์ต 4109, ล็อกอินบัญชี fixture) ด้วย in-app browser ที่ 375 และ 1024 · script วัดอยู่ในหน้า (ไม่ได้เก็บเป็นไฟล์) — ผล PASS/FAIL ด้านล่างมาจากการอ่าน computed style จริง
- ภาพหน้าจอ: เครื่องมือ browser ไม่มีการบันทึกไฟล์ภาพ → **NOT RUN (ไม่มีไฟล์ png)** · ดูภาพแล้ว 3 จอ (Home 375, Scan รอบสแกน 375, เช็คชื่อ 1024) ใช้ประกอบข้อสังเกต
- หมายเหตุ fixture: session หมดอายุเองระหว่างตรวจ 2 ครั้ง (ขึ้น "เข้าสู่ระบบอีกครั้ง") จึงต้องล็อกอินใหม่ — ไม่ใช่ปัญหา UI (เป็นพฤติกรรมของ fixture/ไม่ตรวจต่อ)
- server ปิดแล้ว (หยุดด้วย PID 44988 ตรวจแล้วไม่มี listener บนพอร์ต 4109)

### 1.6 ขนาดและน้ำหนัก (วัดจริงด้วย computed style)

- มีขนาดไอคอน **11 แบบ** ที่ใช้อยู่: 12, 13, 14, 15, 16, 18, 20, 22, 24, 28, 30 (ตัวอย่าง: ไอคอนสถานะ 13, ไอคอนในปุ่ม 14/15/16 ผสม, ใน Shell 20/22/24)
- น้ำหนัก: webfont = เส้น 2px ตัวเดียว (font-weight 400) → น้ำหนักเส้นสม่ำเสมอ **PASS** แต่ไอคอน 12-14px เส้นบางลงตามสัดส่วนอ่านยาก
- `Icon.tsx` รับ prop `stroke` แต่ไม่ใช้ (ไม่มีผล) — ตัดออกหรือเลิกส่ง
- SR: `Icon` ใส่ `aria-hidden` เมื่อไม่มี `title` (ถูกต้อง) · ปุ่มล้วนไอคอนที่พบทุกตัวมี `aria-label` แล้ว (วัด 8 หน้า: ไม่มีปุ่ม/ลิงก์ที่ไม่มีชื่อ) — **PASS**

## 2) ผลตรวจ accessibility (ที่ 375 และ 1024)

| รายการ | ผล | หลักฐาน |
|---|---|---|
| ปุ่ม/ลิงก์/ช่องมี accessible name | PASS | ทั้ง 8 หน้า × 2 ขนาด ไม่มี element ที่ไม่มีชื่อ |

## 4) กติกาไอคอน (สั้น สำหรับทีม)

1. **1 ความหมาย = 1 ไอคอน, 1 ไอคอน = 1 ความหมาย** — ตารางข้อ 1 คือพจนานุกรมกลาง ก่อนเพิ่มไอคอนใหม่ต้องเช็คว่าไม่ซ้ำ
2. **ขนาดมาตรฐานเพียง 2 ขนาด:** 20px (ในปุ่ม ในรายการ เมนู) และ 24px (ปุ่มลอยกลาง หัวหน้า หน้าว่าง = 32 เป็นข้อยกเว้นเดียว) — ไอคอนในป้ายสถานะ/chip ขนาดเล็ก 16px ให้ทำเป็นข้อยกเว้นที่ระบุ (chip เท่านั้น) · ห้าม 12/13/14/15
3. **เส้นเดียว (webfont Tabler 2px)** — ห้ามผสม filled/outline ในกลุ่มเดียวกัน ห้ามใส่ `stroke` prop
4. **ในเมนูและปุ่มที่ทำสิ่งสำคัญ = ไอคอน + คำเสมอ** (แถบข้าง, tab bar มือถือ, เมนู sheet, ปุ่มหลัก) · ไอคอนล้วนได้เฉพาะ: ปิด (x), เพิ่มเติม (dots), ลูกศรเลื่อน, ไฟฉาย/สลับกล้อง
5. **ไอคอนล้วน = ต้องมี `aria-label` ภาษาไทย** · ไอคอนประกอบคำ = `aria-hidden` (Icon.tsx ทำไว้แล้ว)
6. **สีอย่างเดียวห้ามบอกสถานะ** — ต้องมีไอคอนหรือคำควบ · ไอคอนสถานะต้องมีข้อความสำหรับ SR (`title` อย่างเดียวไม่พอ)
7. **สี/contrast:** ไอคอนที่บอกความหมาย ≥ 3:1 · ข้อความ ≥ 4.5:1 · `--text-muted` ห้ามใช้กับข้อความที่ต้องอ่าน
8. **hit target ≥ 44×44px** บนมือถือและ iPad (ขนาดกดได้ ไม่ใช่ขนาดไอคอน)
9. **มี focus ring มองเห็นทุกองค์ประกอบที่โฟกัสได้** (2px `--accent` + offset 2px)
