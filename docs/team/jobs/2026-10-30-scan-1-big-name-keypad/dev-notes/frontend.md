## แก้ตาม code-review (รอบ 1)
- R-01: `.sc-page .scorepad button` / `.sc-page .sc-quick button` ใช้ `min-height: var(--key-h) !important` (specificity สูงกว่า base.css). วัดโดย **จำลอง coarse** (browser ในเครื่องนี้ pointer:fine จึงฉีดกฎ base.css:171/175 แบบไม่มี media เข้าหน้า): ปุ่มเลข/ลัด/บันทึก 65px, ปุ่ม < 44 = 0. ไม่ได้ทดสอบบนอุปกรณ์สัมผัสจริง
- R-02: Feedback มี `awaitScore` (studentId) ซ่อนเฉพาะการ์ด "รับงานแล้ว" ของเด็กที่แป้นเปิด; "ยกเลิกการส่งแล้ว" ฯลฯ แสดงตามเดิม
- R-03: การ์ด role=status ยังอยู่ใน DOM ซ่อนด้วย `.sr-only`; ช่องคะแนน aria-describedby ชี้ชื่อเด็ก (เมื่อมี error ชี้ id error แทน เพราะ test เดิมคาดค่านี้ตรง ๆ)
- R-04: `.sc-page .sc-cell { min-width:0 !important; min-height: var(--tap) !important }` — 820 ตั้ง ช่องกว้าง 28 สูง 44 ไม่ทับกัน ทั้ง fine และจำลอง coarse
- R-05: line-height ชื่อ 1.5 · R-07: ยอมรับ
- R-06: ข้าม — เปลี่ยน aria-label ให้มีค่า ทำให้ test เดิมหา role button name "บันทึก" ไม่เจอ (10 test ล้ม) จึงคง aria-label="บันทึก"
- ผล: typecheck PASS, test 79 ไฟล์/936 PASS, build PASS
