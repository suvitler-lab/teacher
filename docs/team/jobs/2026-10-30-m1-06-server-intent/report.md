# รายงานปิดงาน (S): server ตัดสินเองว่าเป็น "รับงาน" หรือ "ให้คะแนน" + ปุ่มทั้งห้องไม่แตะเด็กยกเว้น + มาเรียนเฉลี่ยแบบรวม

## ทำอะไร

server เคยเชื่อค่าที่เครื่องลูกส่งมาว่าเป็นการ "รับงาน" หรือ "ให้คะแนน" คำขอที่ประกอบเองจึงข้ามการปิดรับงานได้ ตอนนี้ server ตัดสินจากช่องทาง (สแกน/ยิง/พิมพ์เลข = รับงาน · สมุดคะแนน = ให้คะแนน) และรับเฉพาะ 4 ช่องทางที่แอปใช้จริง ปฏิเสธคำขอที่มีรหัสคำสั่งซ้ำ การตัดสินเด็กที่ย้ายออกดูลำดับคำสั่งในคำขอเดียวกันจริง ปุ่ม "ทั้งห้องส่งแล้ว/ให้เต็ม/ล้าง" ไม่แตะเด็กยกเว้น (กล่องยืนยันล้างนับตรงกับที่ล้างจริง) และ "มาเรียนเฉลี่ย" ในหน้านักเรียนคิดแบบรวมทุกคนแล้วหาร (D24) ตรงกับหน้ารายงาน
