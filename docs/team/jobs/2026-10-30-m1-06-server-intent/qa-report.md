## 3. ข้อสังเกต R-01 (ความเสี่ยงต่ำ · ทำซ้ำได้ · **ปิดแล้วใน Verify 1** ตามตัวเลือก ข): method bulk/import/restore ผ่าน batch route = ให้คะแนน

- ประเมิน: **ต่ำ** — ทำได้เฉพาะครูที่เข้าสู่ระบบแล้ว (ไม่มี session = 401) · ความสามารถเท่ากับแตะช่องในสมุดคะแนน (grid) ที่ BR-06/AC-02 อนุญาตอยู่แล้ว · ข้ามกฎเด็กย้ายออก (BR-02) ไม่ได้ (ทดสอบ import/restore/bulk/grid → student_inactive) · ผลข้างเคียงเดียว: บันทึกตรวจสอบเก็บ method ตามที่ client อ้าง
- ตัวเลือก: (ก) คงไว้ตาม BR-06 (ค่าแนะนำ — ไม่เพิ่มความสามารถใหม่) · (ข) ให้ batch schema รับเฉพาะ camera/hid/manual/grid → 422 สำหรับที่เหลือ (ต้องเช็กว่า client/outbox เก่าไม่ส่ง)
