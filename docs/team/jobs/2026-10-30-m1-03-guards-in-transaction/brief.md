## เป้าหมาย / ถือว่าสำเร็จเมื่อ

- ทั้ง 3 จุดตรวจซ้ำ**ในธุรกรรมเดียวกับการเขียน** ด้วยรูปแบบที่มีอยู่แล้ว: `abortIf(...)` วางหน้า batch (`worker/lib/guard.ts`) และใน `catch` อ่านข้อมูลสดเพื่อตอบรหัสข้อผิดพลาดเดิม (แบบเดียวกับ `studentHistoryGuard` และ `lowersBelowScores`)
- คำขอที่แพ้ได้รหัสข้อผิดพลาดเดิม (409/422 พร้อมข้อความไทยเดิม) ไม่ใช่ 500 และไม่มีอะไรถูกเขียนครึ่งเดียว
- ไม่มี migration · ไม่เพิ่ม unique index (D07) · สัญญา API คงเดิม
