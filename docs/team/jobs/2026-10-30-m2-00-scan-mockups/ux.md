## ผู้ใช้และงานหลัก

ครูคนเดียว ใช้ iPad เป็นหลัก (แนวตั้งตอนสแกน, แนวนอนตอนฉายทีวี) · งานหลัก: ยิง/ถ่าย QR → ให้คะแนน → ยิงคนถัดไป · ดูสมุดคะแนนหลายสิบงานโดยไม่หลง · อ่านตัวอักษรสบายตา

## 1) หน้าสแกน — สิ่งที่ "ไม่เปลี่ยน" (D29)

ผังเลขที่แบบเดิม 8 คอลัมน์ (ช่อง ~31×44, ชื่อเล่น 11px) · สีช่องเดิม (เขียว ส่งแล้ว / ฟ้า รับแล้วรอคะแนน / เหลือง สาย / ขอบประแดง ยังไม่ส่ง) · แถบหัวรอบ, ป้ายเครื่องยิง/ออนไลน์, การ์ดสแกนล่าสุด, ปุ่มกล้อง · **ไม่มีคิว "รอคะแนน (n)"** · "ให้คะแนนทีหลัง" พฤติกรรมเดิม · ติ๊ก/ขีดคงเดิม (สมุดคะแนน ✓ = ส่งแล้ว, – = ยังไม่ส่ง)

## 2) หน้าสแกน — สิ่งที่แก้ (เฉพาะจุดติดขัด)

| จุด | ก่อน (วัดจาก scan.css/ภาพจริง) | หลัง (iPad ตั้ง 820) |
|---|---|---|
| ชื่อนักเรียนหลังสแกน (โหมดกรอกทีละคน) | 17px ในการ์ดเล็ก และซ้ำกับการ์ดแจ้งผล | **34px ตัวหนา** + เลขที่ 22px · การ์ดแจ้งผลซ้ำถูกแทนด้วยหัวการ์ดนี้ขณะรอคะแนน (คืนหลังบันทึก) |
| ช่องคะแนน | 150×52 | **190×88, ตัวเลข 52px** |
| ปุ่มเลข | 56×52 ใช้ 40% ความกว้าง ขวาว่าง | **3 คอลัมน์ 134×64** ใช้ครึ่งขวาของการ์ด + ปุ่ม "บันทึก 8/10" กว้างเต็ม 64px |
| ปุ่มลัดคะแนน | ชิป 26px สูง | ปุ่ม 64px สูง 2 คอลัมน์ (10/10, 9/10, 8/10, 5/10, "ล่าสุด 7.5") |
| ปุ่ม/ป้ายที่ < 44px | ปุ่ม จบรอบ/ทดสอบ ฯลฯ 30–36px | ทุกปุ่ม ≥ 44px (วัด 0 ตัวเล็กกว่า) · ช่องผังสูง 38→44 (กว้างยังเดิม) |

การ์ดคะแนนสูง 440px พอดีเท่าเดิม → **iPad ตั้ง ทั้งหน้าพอดี 1180 ไม่ต้องเลื่อน** (วัดใน mockup) · iPad นอน/คอม: 2 คอลัมน์ ซ้าย 560/520px = สแกน+คะแนน+ล่าสุด ขวา = ผัง (พอดีจอ) · มือถือ: คอลัมน์เดียว, ผัง 6 คอลัมน์ (เลื่อนหน้า)
**กล้อง iPad**: เปิดแล้วแถวกล้องขนาด 4:3 (กว้าง ≤ 460px) + ช่องข้างแสดงชื่อ/สถานะล่าสุด (ใช้พื้นที่ขวาที่เดิมว่าง) · แป้น/ผัง **ขนาดเท่าเดิม ไม่ถูกบีบ** แต่หน้าเลื่อนลง (+311px บน iPad ตั้ง) · ช่องสแกนอยู่บนสุดเสมอ
**แก้แถบหัวรอบ sticky ซ้อน**: เลิก sticky แถบหัวรอบ, ให้ช่องสแกนเป็นตัว sticky เดียวบนจอคอลัมน์เดียว
**สลับโหมดกลางรอบ (ตัวเลือก ไม่เปลี่ยนหน้าตา)**: ข้อความ "เต็ม 10 · กรอกทีละคน" เดิมเป็นปุ่ม 44px ▾ แตะเปิดเมนู 3 โหมด (64px/แถว) ใช้กับการสแกนครั้งถัดไป · ที่เหลือจากแผน M2 คงเป็นตัวเลือก: การ์ด "สแกนต่อจากครั้งก่อน", จำค่าล่าสุด, action sheet แตะช่องที่ส่งแล้ว + toast เลิกทำ 5 วิ (D16), dialog bulk ยืนยัน, ป้าย "เครื่องยิงพร้อม" + ปุ่ม "ทดสอบ", ปุ่มโหมดฉายจอที่หัวรอบ (ดู scan.html)

## 3) ตั้งค่า → ทั่วไป: ขนาดตัวอักษร + ความหนาแน่น (`settings.html`, ตามภาพอ้างอิง)

- แถว **ขนาดตัวอักษร**: ปุ่ม − (56px) [ค่า px] + (56px) + ปุ่ม "ค่าเริ่มต้น" · ช่วง 14–24 ครั้งละ 1 · เริ่มต้น **18** บนจอสัมผัส/iPad (อ้างอิงแอปอื่น 16; วัดระบบจริงตอนนี้ 11–13) และ 16 บนคอม · **ใช้ทั้งแอป จำต่อเครื่อง** (`localStorage`) · หน้าตั้งค่าเปลี่ยนทันทีที่กด + การ์ด "ตัวอย่างสด" (หัว/รอง/แถวตาราง/ป้าย/ปุ่ม)
- แถว **ความหนาแน่น** กระชับ / ปกติ / โปร่ง = ความสูงแถว/ปุ่ม 2.6 / 3.2 / 3.9 × ขนาดตัวอักษร **แต่ไม่ต่ำกว่า 44px** (บนจอสัมผัส) → ที่ 18px: 47 / 58 / 70px
- **แทนตัวปรับ 3 ระดับ (ปกติ/ใหญ่/ใหญ่มาก) เดิมทั้งหมด**; ตัวปรับของโหมดฉายจอ (D27) แยกต่างหาก
- type scale (เป็น em ของ px ที่ตั้ง): หลัก 1.0 · รอง 0.9 (≥ 14px) · ป้าย 1.0 (≥ 16 ที่ 18px) · หัวคอลัมน์ 0.85 ตัวหนา · หัวหน้า 1.5 · line-height ไทย 1.6/หัว 1.35 · ต้องเลิก px ตายตัวใน CSS (ใช้ rem/`--fs`)
- เช็คชื่อ (`pages.html`): ปุ่มสถานะ 64px ไอคอน+คำ, ช่องเด็ก 4 คอลัมน์ 170×64 (ที่ 18px ไม่ล้น) · รายงาน: ตารางล่างใช้ตัวเลขเดียวกัน เลื่อนในกรอบ (ยังไม่ทำ mockup)

## 4) สมุดคะแนน 10–15 คอลัมน์ (`gradebook.html` 14 งาน × 44 คน)

หลักการ: **ชื่อและสะสมค้างไว้ ตัวกลางเลื่อน** เหมือนภาพที่ชอบ (หัวคอลัมน์ย่อ + แถบสี + แถบความคืบหน้า, ช่อง pill ✓/–/คะแนน)

| ปัญหา "หลง/รก" | วิธี |
|---|---|
| เลื่อนแล้วลืมว่าแถวใคร | **ล็อกซ้าย: เลขที่+ชื่อ** (150→330px ตามขนาดจอ/ตัวอักษร) + เงาขอบ · จุดแดงหน้าชื่อ = มีงานค้าง (ตามภาพจริง) |
| ลืมยอดรวม | **ล็อกขวา: สะสม** (5.2em) · หัวตารางค้างบน 2 ชั้น |
| หัวยาว | หัวคอลัมน์ 2 บรรทัดตัดด้วย "…" + "เต็ม 10 · ก.ย." + **แถบสีประเภทงาน 4px ด้านบน** + **แถบความคืบหน้าส่งแล้ว** (6px) แตะหัว = เปิดรายละเอียดงาน |
| งานเยอะ | **จัดกลุ่ม** ไม่จัด/ตามประเภท/ตามเดือน: แถวหัวกลุ่มสีประเภท "ใบงาน · 6 งาน" ติดซ้ายขณะเลื่อน · **แตะพับกลุ่ม** → เหลือ 1 คอลัมน์ "รวม {กลุ่ม}" (เช่น 38/50) · ปุ่ม "พับทุกกลุ่ม/กางทั้งหมด" |
| หลงตำแหน่ง | **แถบย่อ (minimap)** แสดงทุกงานเป็นแถบสีประเภท + กรอบ "ช่วงที่เห็น" · ปุ่มกระโดด "ใบงาน / แบบฝึกหัด / สอบย่อย / โครงงาน" (44px) · scroll-snap ทีละคอลัมน์ · เงาขอบซ้าย/ขวา |
| ไม่อยากเห็นทุกคอลัมน์ | ปุ่ม "คอลัมน์ (14/14)" → เลือกแสดงตามประเภท, คอลัมน์สะสม, แถบความคืบหน้า |
| bulk กดพลาด | รวมเป็นเมนู "ทำทั้งห้อง ▾" (ส่งแล้ว / ให้เต็ม / เส้นคั่น / **ล้างคะแนนทั้งงาน…** แดงล่างสุด) + dialog ยืนยันบอกจำนวนคน (D16) · "ซ่อนคะแนน" แยกปุ่ม |

ขนาดวัดจริง (คอลัมน์ 4.9em, แถว 3.2em, ไม่ต่ำกว่า 44px):

| จอ | 14px | 16px | 18px | 24px | เห็นพร้อมกันที่ 16px |
|---|---|---|---|---|---|
| iPad ตั้ง (พื้นที่ตาราง 707) | ตาราง 1164 · แถว 45 | 1331 · 51 | 1497 · 58 | 1996 · 77 | ~6 คอลัมน์ (กลาง 474px) |
| iPad นอน (1067) | 1199 | 1371 | 1542 | 2056 | ~10 คอลัมน์ |
| คอม (1327) | **1327 พอดี ไม่เลื่อน** | 1401 | 1576 | 2101 | ~14 คอลัมน์ (เลื่อนเล็กน้อย) |

→ ไม่ลดตัวอักษรเพื่อให้พอดี · ปุ่ม < 44px = 0 ทุกชุดที่วัด · หัวตารางสูง 101–165px ที่ 14–24px (กินพื้นที่; แก้ด้วยพับหัวกลุ่มได้)

## Flow ของหน้าสแกน (ย่อ — ตามแผน M2)

1. หน้าหลัก → การ์ด "สแกนต่อจากครั้งก่อน" (ตัวเลือก) → "สแกนต่อ" 1 แตะ · หรือ ตั้งค่ารอบที่เลือกไว้ให้ → "เริ่มสแกน"
2. ยิง/ถ่าย QR → ชื่อ 34px + แป้น → พิมพ์/แตะ → "บันทึก 8/10" (Enter) → การ์ดแจ้งผลกลับ
3. แตะช่องที่ส่งแล้ว → action sheet (แก้คะแนน / ยกเลิกการส่ง / ปิด) → ยกเลิก → toast "เลิกทำ (5)"
4. "ทำทั้งห้อง ▾" → dialog "ให้เต็ม 23 คน?" โฟกัสเริ่มที่ "ยกเลิก" → toast เลิกทำ
5. จบรอบ → สรุป (ยังไม่ส่ง · คัดลอกรายชื่อ)

## สถานะ ข้อความ การเข้าถึง (ย่อ)

- ว่าง/โหลด/error/สำเร็จ/ไม่มีสิทธิ์: ตามรอบก่อน — ผังว่าง "ยังไม่มีใครส่ง — ยิงได้เลย" · งานปิด แถบแดง "งานนี้ปิดรับแล้ว" · ออฟไลน์ ป้าย "ออฟไลน์ · รอส่ง n" · ไม่มีสิทธิ์ N/A (ครูคนเดียว)
- microcopy: สแกนต่อ · เริ่มสแกน · บันทึก 8/10 · ให้คะแนนทีหลัง · ยืนยัน "ให้เต็ม 23 คน" / "ยกเลิก" · "ยกเลิกการส่งของเลขที่ 12 แล้ว · เลิกทำ (5)"
- a11y: ช่องคะแนน `aria-label`, ปุ่ม −/+ มี aria-label, ค่าขนาด `aria-live`, หัวคอลัมน์ `scope=col`, ตารางเลื่อนได้ด้วยคีย์บอร์ด (M3-01), dialog Esc ปิด, ช่องผัง "เลขที่ 12 ดวงดาว ส่งแล้ว", ไม่พึ่งสีอย่างเดียว (✓/– /ลายเฉียงยกเว้น)

## คำถามเจ้าของงาน (≤ 3, ค่าแนะนำที่ PM ใช้ถ้าไม่ตอบ)

1. ผังเลขที่เดิมตัดชื่อเล่นที่ iPad ตั้ง — เพิ่มตัวเลือก "ผังใหญ่" (ช่องกว้าง 81px เห็นชื่อเต็ม) ในตั้งค่าไหม? แนะนำ: **ไม่ทำตอนนี้** คงผังเดิม; ตัวปรับขนาดตัวอักษรจะขยายผังตามอยู่แล้ว
2. ขนาดตัวอักษรเริ่มต้นบน iPad = 18px (ภาพอ้างอิง 16)? แนะนำ: **18** ปรับ −/+ ได้
3. สมุดคะแนนเริ่มต้น "ไม่จัดกลุ่ม" หรือ "ตามประเภท"? แนะนำ: **ตามประเภท พับกลุ่มที่เก่าเกิน 1 เดือนอัตโนมัติ** (เลือกเองได้)
