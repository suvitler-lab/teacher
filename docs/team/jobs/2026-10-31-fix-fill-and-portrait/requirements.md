# Requirements: ตารางเต็มจอเมื่องานน้อย + หน้าสแกนแนวตั้งเห็นชื่อเต็ม (fix-fill-and-portrait)

โดย System Analyst · 2026-11-02 · สถานะ: ร่าง

## ปัญหาและเป้าหมาย

จากภาพ iPad จริงของครู (reference.md รูป 1-4): (1) สมุดคะแนนที่มีงานน้อย (เช่น 2 ใบงาน) ตารางหยุดที่คอลัมน์สะสม ขวามือว่าง ดูไม่เรียบร้อย ทั้งแนวตั้ง/แนวนอน — ครูต้องการให้ตารางเต็มจอเมื่องานน้อย และค่อยหดแล้วเลื่อนเมื่องานเยอะ "เหมือนแบบเก่า" (2) หน้าสแกนแนวตั้ง ผังเลขที่ถูกบีบอยู่ครึ่งขวา ชื่อเล่นเหลือ 1-2 ตัวอักษร ครูดูไม่ออกว่าใครส่งแล้ว — แนวนอนดีอยู่แล้วห้ามเปลี่ยน (3) ทีมต้องถ่ายภาพหน้าจอจริงขนาด iPad ให้ครูดูก่อนส่งงาน เพื่อไม่ต้องแก้วนไปมา

## User stories

- US-01: ในฐานะครู ฉันต้องการให้สมุดคะแนนที่มีงานน้อยยืดเต็มความกว้าง เพื่อให้หน้าดูเรียบร้อย ไม่มีที่ว่างแปลก ๆ
- US-02: ในฐานะครู ฉันต้องการให้สมุดคะแนนที่มีงานเยอะยังเลื่อนได้โดยชื่อและสะสมค้างไว้เหมือนเดิม เพื่อไม่หลงแถว
- US-03: ในฐานะครู ฉันต้องการเห็นชื่อเล่นบนผังเลขที่ตอนถือ iPad แนวตั้ง เพื่อรู้ทันทีว่าใครส่งแล้ว/ยังไม่ส่ง
- US-04: ในฐานะครู ฉันต้องการเห็นภาพหน้าจอจริงขนาด iPad ก่อนทีมส่งงาน เพื่อตัดสินจากภาพไม่ใช่คำอธิบาย

## กฎธุรกิจ

ไม่มีกฎธุรกิจใหม่ (ไม่แตะสูตรคะแนน/สะสม/รวมกลุ่ม) · ตัวอย่างการจัดความกว้างสำหรับ QA (AC-01/03, ค่าสมมติ): กรอบ 707px, ชื่อ 200px, สะสม 80px, งานต่ำสุด 88px/คอลัมน์ → 2 งาน: 200+80+2×88 = 456 ≤ 707 → แต่ละงานกว้าง (707−200−80)/2 = 213.5px · 6 งาน: 200+80+6×88 = 808 > 707 → งานกว้าง 88px เลื่อนในกรอบ

## ข้อจำกัดกลาง

- ห้ามแตะสูตรคะแนน, worker, schema, outbox, ประวัติการแก้ไข · ไม่เพิ่ม dependency · ห้าม deploy/merge จนเจ้าของงานดูภาพจริงและอนุมัติ (Gate 2)
- ข้อมูลสมมติเท่านั้น ห้ามชื่อนักเรียนจริงในโค้ด/test/ภาพ/เอกสาร · ภาพ PNG ไม่เข้า repo
- คงพฤติกรรม D29/D30: ผังเลขที่แบบเดิม 8 คอลัมน์ (มือถือ 6) สีช่องเดิม ติ๊ก/ขีดเดิม ไม่มีคิวรอคะแนน · สมุดคะแนนล็อกชื่อ/สะสม หัวค้าง แถบย่อ ปุ่มกระโดด เมนูคอลัมน์ ค่าเริ่มต้นไม่จัดกลุ่ม/กางทุกกลุ่ม แตะ "รวม" เพื่อแก้ (gb-1a/1b/2)
- งานนี้แทนข้อ "คอลัมน์งานไม่ยืดเกิน ~9rem ตารางชิดซ้ายได้" ของ gb-2 AC-03 (ตามคำเจ้าของงาน 31 ต.ค.) — ส่วนเพดานคอลัมน์ชื่อ ~18rem และไม่มีแถบเลื่อนซ้อนยังคงอยู่

## ไม่ทำในรอบนี้

- ผังเลขที่ขนาดใหญ่/เปลี่ยนจำนวนคอลัมน์ผัง (D30) · เปลี่ยนหน้าตาหน้าสแกนแนวนอน · หน้าอื่นนอกสมุดคะแนนและหน้าสแกน · โหมดฉายจอ · motion/animation (Gate 0: "ไม่ต้อง") · ใส่ภาพเข้า repo หรือ CI ทดสอบภาพอัตโนมัติ

## สมมติฐาน

- "แบบเก่า" = ตารางก่อน gb-1a ที่คอลัมน์งานแบ่งพื้นที่ที่เหลือเท่า ๆ กัน · ยืดเฉพาะคอลัมน์งาน (และ "รวม" เมื่อพับ) ไม่ยืดชื่อ/สะสม
- เส้นแบ่งแนวตั้ง/แนวนอนของหน้าสแกน = 1000px · มือถือ (< ~600px) คงเดิม
- PM แก้ CSS ไปก่อน Gate 0 (grade.css, scan.css) ถือเป็นร่างแรก ต้องผ่าน AC ทั้งหมดใหม่
